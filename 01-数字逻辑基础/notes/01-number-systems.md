# 数制

## 为什么计算机使用二进制

数字计算机使用二进制（binary，base-2）数制，其根本原因在于物理可靠性。二进制系统仅用两种状态来表示信息——通常是 0 V（低电压）和 Vdd（高电压）。与十进制所需的十个电平相比，这两种离散电压电平要可靠地区分开容易得多。噪声容限、工艺偏差以及器件老化都会损害信号完整性；而只有两种状态时，系统在 0 被误判为 1 或反之之前，能够容忍显著的性能退化。

二进制的主要优势：
- **抗噪声能力（noise immunity）**：可以设置具有宽裕量的电压阈值（例如 TTL 逻辑：逻辑 0 为 0-0.8 V，逻辑 1 为 2.0-5.0 V）。
- **简单的开关器件**：晶体管天然作为开关工作（MOSFET 中的截止区与线性区/三极管区），直接映射到 0/1。
- **布尔代数（Boolean algebra）**：二进制可以清晰地映射到布尔逻辑，从而实现电路的形式化设计与优化。
- **错误检测**：二进制编码（奇偶校验、CRC、汉明码）提供了直接的错误检测与纠正能力。

与 Patterson 和 Hennessy 关于硬件/软件接口的论述一致，二进制位的二值特性与数字信号的通断行为相匹配 [1]。

## 二进制表示

二进制数是一个比特（bit，二进制位）序列，每一位为 0 或 1。每一位的位权是 2 的幂。

**示例**：二进制数 `1011_2`（下划线将半字节分组以便阅读）：

```
1    0    1    1
2^3  2^2  2^1  2^0
8    4    2    1
```

值 = 1x8 + 0x4 + 1x2 + 1x1 = 十进制的 11。

### 转换：二进制转十进制

将每一位乘以其位权后求和。

**示例**：将 `11010_2` 转换为十进制。

| 位  | 位权        | 贡献值       |
|-----|-------------|-------------|
| 1   | 2^4 = 16    | 16          |
| 1   | 2^3 = 8     | 8           |
| 0   | 2^2 = 4     | 0           |
| 1   | 2^1 = 2     | 2           |
| 0   | 2^0 = 1     | 0           |

**结果**：16 + 8 + 2 = **26**。

### 转换：十进制转二进制

使用连续除以 2 的方法。每一步的余数就是下一个最低有效位（least significant bit，LSB）。

**示例**：将 42 转换为二进制。

```
42 / 2 = 21 remainder 0 (LSB)
21 / 2 = 10 remainder 1
10 / 2 =  5 remainder 0
 5 / 2 =  2 remainder 1
 2 / 2 =  1 remainder 0
 1 / 2 =  0 remainder 1 (MSB)
```

从上到下读取余数得到：**101010_2**。

## 十六进制表示

十六进制（hexadecimal，base-16）使用数字 0-9 和字母 A-F。它是二进制的一种紧凑记法：一个十六进制数字恰好表示四位。

| 十六进制 | 二进制 | 十进制 |
|-----|--------|---------|
| 0   | 0000   | 0       |
| 1   | 0001   | 1       |
| 2   | 0010   | 2       |
| 3   | 0011   | 3       |
| 4   | 0100   | 4       |
| 5   | 0101   | 5       |
| 6   | 0110   | 6       |
| 7   | 0111   | 7       |
| 8   | 1000   | 8       |
| 9   | 1001   | 9       |
| A   | 1010   | 10      |
| B   | 1011   | 11      |
| C   | 1100   | 12      |
| D   | 1101   | 13      |
| E   | 1110   | 14      |
| F   | 1111   | 15      |

### 转换：二进制转十六进制

从右端开始将比特每四位分为一组，然后转换每一组。

**示例**：`101110101001_2` -> `1011 1010 1001` -> `B A 9` -> **0xB A9**。

### 转换：十六进制转二进制

用每个十六进制数字对应的 4 位二进制数替换它。

**示例**：`0x3F 7` -> `3` = `0011`，`F` = `1111`，`7` = `0111` -> **001111110111_2**。

## 补码（two's complement，有符号数）

补码是计算机中表示有符号整数的主导方法，因为它统一了加法与减法：同一套硬件即可处理无符号数和有符号数的加法运算。

### 表示方法

对于 n 位数：
- 最高有效位（most significant bit，MSB）的位权为 **-2^(n-1)**（负权重）。
- 其余所有位均具有通常的正权重。

**范围**：-2^(n-1) 到 2^(n-1) - 1。对于 8 位：-128 到 127。

### 求负数

要计算 n 位数的 -X：
1. 用二进制写出 X（n 位）。
2. 将所有位取反（按位 NOT）。
3. 加 1。

**示例**：用 8 位补码表示 -5。

1. +5 = `00000101`
2. 取反：`11111010`
3. 加 1：`11111011`

因此，8 位补码中的 -5 为 `11111011`。

### 符号扩展（sign extension）

要拓宽一个补码数，将符号位（MSB）延伸至新的高位中。

**示例**：将 4 位的 `1011`（-5）扩展为 8 位：`11111011`。

### 加法与减法

使用标准二进制加法对补码数求和，并丢弃从 MSB 溢出的最终进位。当进入符号位的进位与从符号位输出的进位不同时，发生溢出。

**示例**：5 + (-3) = 2。

```
  00000101  (+5)
+ 11111101  (-3)
----------
1 00000010  (carry out discarded -> +2, correct)
```

### 补码为何有效

取负过程（取反 + 加 1）等价于计算 2^n - X。将 -X = 2^n - X 加到 X 上得到 2^n，即模 2^n 下的 0。这意味着加法电路可以完全是组合逻辑——不需要专门的减法器硬件 [1]。

## IEEE 754 浮点数

IEEE 754 标准 [2] 定义了以二进制表示实数的格式。单精度（single-precision，32 位）格式是教学中最为常见、使用最广泛的格式。

### 单精度格式（32 位）

```
Bit 31      Bits 30-23        Bits 22-0
[ Sign ]   [ Exponent ]      [ Mantissa/Significand ]
   1 bit      8 bits              23 bits
```

| 字段     | 宽度 | 用途                                              |
|-----------|-------|------------------------------------------------------|
| 符号（Sign，S）  | 1 位 | 0 = 正，1 = 负                           |
| 指数（Exponent，E） | 8 位 | 偏置表示法（biased representation；实际指数 = E - 127） |
| 尾数（Mantissa，M） | 23 位 | 小数部分（前导 1 是隐含的）       |

### 数值公式

对于**规格化数（normalized numbers）**（E 不全为 0 也不全为 1）：

**值 = (-1)^S x (1.M) x 2^(E - 127)**

前导 1（即“隐藏位”，hidden bit）是隐含的，并不存储，从而提供 24 位的精度。

### 偏置指数（biased exponent）

存储的指数 E 是实际指数加上 127（偏置值，bias）。这使得指数范围为 -126 至 +127（E = 1 至 254）。E = 0 与 E = 255 保留用于特殊值。

### 示例：将 5.75 转换为 IEEE 754 单精度

**第 1 步**：转换为二进制。
- 整数部分：5 = `101_2`
- 小数部分：0.75 = `0.11_2`（因为 0.75 x 2 = 1.50 -> 1；0.50 x 2 = 1.00 -> 1）
- 合并：`101.11_2`

**第 2 步**：规格化。
- `101.11_2` = `1.0111_2 x 2^2`
- 符号：0（正）
- 指数：2 + 127 = 129 = `10000001_2`
- 尾数：`01110000000000000000000`（前导 1 被去掉）

**第 3 步**：打包。

```
0 10000001 01110000000000000000000
```

用十六进制表示为：`0x40B80000`。

### 示例：将 0.1 转换为 IEEE 754 单精度

0.1 的二进制表示是**循环小数（repeating fraction）**：0.00011001100110011001100...

```
0.1 = 0.000110011001100110011001100..._2
    = 1.10011001100110011001100..._2 x 2^(-4)
```

- 符号：0
- 指数：-4 + 127 = 123 = `01111011_2`
- 尾数：`10011001100110011001101`（舍入到 23 位）

```
0 01111011 10011001100110011001101
```

用十六进制表示为：`0x3DCCCCCD`。

这揭示了一个关键问题：许多十进制小数无法用二进制精确表示——存储的值只是一个接近的近似值，而非精确的 0.1 [3]。

### 特殊值

| 指数 | 尾数 | 含义                             |
|----------|----------|-------------------------------------|
| 0        | 0        | 零（带符号：存在 +0 和 -0）      |
| 0        | 非零 | 非规格化数（denormalized/subnormal numbers）    |
| 255      | 0        | 无穷大（带符号：+inf、-inf）       |
| 255      | 非零 | NaN（非数，Not a Number）                  |

### 非规格化数（denormalized numbers）

当 E = 0 且 M != 0 时，该数为非规格化数：隐含的前导位为 0，指数为 -126（而非 -127）。这允许逐渐下溢（gradual underflow）——表示比最小规格化数更接近零的数。

**值 = (-1)^S x (0.M) x 2^(-126)**

### 双精度（64 位）

| 字段    | 宽度 | 偏置值   |
|----------|-------|--------|
| 符号     | 1     | --     |
| 指数 | 11    | 1023   |
| 尾数 | 52    | --     |
