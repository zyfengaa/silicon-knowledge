# 07 — 封装与测试成本

> 一句话结论：**先进 AI 芯片的成本不止是裸片（Die）：基板上晶圆上芯片封装（CoWoS）的中介层、高带宽内存（HBM）堆叠、基板、凸点与多轮测试常常占到整包物料清单（Bill of Materials, BOM）的很大一块，而且封装良率会把多颗 die 的良率相乘。**

## 为什么讲这个

在 2.5D/3D 封装时代，封装不再是“把芯片装进塑料壳”的低成本后道工序。以 HBM 为核心的 AI 加速器，需要把多颗逻辑 die、多个 HBM 堆栈、硅中介层、有机基板与散热结构集成在一个封装内；**任何一颗 die 或任何一道键合失败，整包都可能报废**。封装因此同时是成本中心、良率瓶颈与产能瓶颈。

测试也不是免费的“最后一道检查”。晶圆探针、老化筛选、终测与系统级测试（System-Level Test, SLT）各自消耗机时、探针卡/插座与工程资源；测试覆盖不足会带来现场失效，覆盖过度则会把成本推高到不可接受。**KGD（Known Good Die）与测试策略，直接决定多 die 封装的良率上限。**

本篇承接 [06 Die 成本](06-die-cost.md) 与 [05 良率模型](05-yield-models.md)，封装工艺细节见 [07 先进封装](../../13-工艺制造与先进封装/notes/07-advanced-packaging.md)，HBM 结构与成本量级见 [HBM 与 GDDR](../../05-存储层次/notes/08-hbm-and-gddr.md)。集群层的 TCO 与 $/token 见 [why-ai-cluster](https://github.com/zyfengaa/why-ai-cluster/blob/main/README.md)。

## 核心概念

### 1. 成本边界：从 die 到封装后成品

封装后单颗成本可写成：

```
C_package_unit ≈ (Σ C_die + C_materials + C_assembly + C_test) / Y_package + NRE_pkg / Q
```

其中：

- `Σ C_die`：所有逻辑 die、HBM 堆栈、base die 的成本，均应为**合格 die 成本**；
- `C_materials`：基板、中介层、凸点、底部填充（Underfill）、盖板（Lid）、热界面材料（Thermal Interface Material, TIM）等材料；
- `C_assembly`：贴装、回流、键合、塑封、组装与返修；
- `C_test`：晶圆探针、老化、终测、SLT 的机时与耗材；
- `Y_package`：封装良率，把材料与组装成本整体放大；
- `NRE_pkg / Q`：封装设计、测试程序、探针卡/插座、可靠性认证按产量摊销。

注意：`Y_package` 与 die 良率不是同一件事。die 良率已在 `C_die` 中体现；`Y_package` 反映的是**封装过程**中的新损失，例如键合偏移、空洞、翘曲、基板缺陷与测试误杀。

### 2. KGD：多 die 封装的生死线

**已知合格 die（Known Good Die, KGD）** 指在堆叠或组装前已经过充分测试、可视为合格的裸片。多 die 封装的良率近似为：

```
Y_package ≈ Y_KGD^n × Y_assembly × Y_final_test
```

以 8 个 HBM 堆栈、每个 12-Hi（96 颗 DRAM die）为例：

- 若每颗 die 的 KGD 良率为 99.5%，且组装良率 99%，则 `0.995^96 × 0.99 ≈ 61%`；
- 若 KGD 提升到 99.9%，则 `0.999^96 × 0.99 ≈ 90%`。

**KGD 从 99.5% 提升到 99.9%，整包良率从约 61% 提升到约 90%**。这就是为什么 HBM 与 chiplet 产品要在堆叠前做晶圆级测试、修复与筛选，而不能把希望寄托在最终测试上。

### 3. 测试流程：四道关卡

| 阶段 | 目的 | 典型内容 | 成本驱动 |
|------|------|----------|----------|
| 晶圆探针/分选（Wafer Probe/Sort） | 剔除坏 die、分档、修复 | DC/AC 参数、功能、速度分档、eFuse、存储冗余修复 | 探针卡、探针接触次数（Touchdown）、测试时间、并行 site 数 |
| 老化筛选（Burn-in） | 筛除早期失效 | 高温/高压偏置、动态向量、时间筛选 | 老化板、炉时、温度、功耗 |
| 终测（Final Test） | 封装后功能与参数确认 | 功能、频率、功耗、IO、边界扫描 | 测试机时、插座、分选机（Handler）、温度 |
| 系统级测试（SLT） | 模拟真实系统负载 | 板级/整机级 workload、AI kernel、互连压力 | 测试时间（可达小时级）、治具、系统成本 |

此外还有**可靠性认证（Qualification）**：按 JEDEC 标准做高温工作寿命、温度循环、湿热、机械冲击等，属于 NRE/认证成本，不是逐颗成本，但会显著影响上市时间与封装方案选择。

### 4. 测试成本模型

单颗测试成本的一阶近似：

```
C_test ≈ (R_tester × t_test) / (3600 × N_site) + C_fixture / N_touchdown + C_handler
```

其中 `R_tester` 为测试机小时费率（美元/小时），`t_test` 为单颗测试时间（秒），`N_site` 为并行测试 site 数。示例（**示例假设，不构成采购/报价依据**）：

- 晶圆探针：60 s、150 美元/小时、8 site → 约 0.31 美元/die；
- 终测：180 s、100 美元/小时、8 site → 约 0.63 美元/颗；
- SLT：1,800 s、50 美元/小时、1 site → 约 25 美元/颗；若 3,600 s，则约 50 美元/颗；
- 探针卡/插座摊销与 handler：另加数美元至数十美元。

**测试时间是最强杠杆**：SLT 从 30 分钟延长到 1 小时，成本近似翻倍。多 site 并行、测试向量压缩、自适应测试与内建自测试（Built-In Self-Test, BIST）都是降低单位测试成本的手段。

### 5. 封装成本构成

先进封装的材料与工艺可以拆成六块：

1. **基板（Substrate）**：ABF（Ajinomoto Build-up Film）有机基板，层数、线宽/线距、尺寸与翘曲控制决定价格；大封装需要更多层与更严格平整度。
2. **中介层（Interposer）**：硅中介层（CoWoS-S）、重分布层（Redistribution Layer, RDL）中介层（CoWoS-R）或局部硅桥（CoWoS-L）。面积以“掩模版倍数（Reticle Multiple）”计量，面积越大，每片晶圆可排数越少、缺陷概率越高。
3. **凸点（Bump）/微凸点（Microbump）**：数量、间距、共晶/铜柱/混合键合工艺。UCIe 标准封装凸点间距约 100–130 µm，先进封装约 25–55 µm；间距越小，单位面积互连密度越高，工艺难度与成本也越高。
4. **硅通孔（Through-Silicon Via, TSV）与堆叠**：HBM 的 TSV、微凸点、base die 与堆叠良率；HBM4 引入更宽接口与混合键合，封装复杂度继续上升。
5. **组装（Assembly）**：贴装、回流、底部填充（Underfill）、塑封、盖板（Lid）、热界面材料（Thermal Interface Material, TIM）、翘曲控制与返修。
6. **测试与可靠性**：上表中的四道关卡，以及封装级可靠性认证。

### 6. 为什么先进封装贵

- **面积驱动的良率损失**：中介层面积从 1× 掩模版增到 3.3×，每片晶圆可排数下降、缺陷命中的概率上升，成本呈超线性增长。
- **多 die 良率相乘**：8 个 HBM 堆栈、96 颗 DRAM die，任何一颗坏 die 都可能毁掉整包；KGD 与修复是必需项。
- **工艺步骤多、容错低**：TSV、细间距凸点、混合键合、大面积 underfill、翘曲控制，每一步都有专属设备与工艺窗口。
- **材料贵**：大尺寸 ABF 基板、硅中介层、临时键合胶、underfill、TIM、lid 都不便宜。
- **测试时间长**：SLT、老化与系统级验证占用昂贵机时，先进封装还增加互连与堆叠测试。
- **产能与供应链集中**：CoWoS 等先进封装产能长期紧张，价格不完全由成本决定，还受配额与合约影响。

### 图 2：多 die 良率相乘

```
Y_package ≈ Y_KGD^(DRAM die 数) × Y_assembly × Y_test

99.5% KGD, 96 颗 DRAM, 99% 组装 → 0.995^96 × 0.99 ≈ 61%
99.9% KGD, 96 颗 DRAM, 99% 组装 → 0.999^96 × 0.99 ≈ 90%
2 颗逻辑 die 95%, 中介层 95%, 组装 98% → 0.95² × 0.95 × 0.98 ≈ 84%
```

每多一颗 die、每降低一个百分点的 KGD，整包良率都会明显下降。封装测试的第一目标不是“测出所有坏 die”，而是**在成本最低的环节尽早剔除坏 die**。

## 深入理解

### 1. 测试覆盖与缺陷逃逸：Williams–Brown 关系

测试成本必须和**逃逸成本**一起看。Williams 与 Brown（1981）给出缺陷水平（Defect Level, DL）与良率 Y、故障覆盖率 T 的经典近似：

```
DL ≈ 1 - Y^(1-T)
```

DL 也常换算为**每百万件缺陷数（Defects Per Million, DPPM）**。以 Y = 45% 为例：

| 故障覆盖率 T | 缺陷水平 DL | 约合 DPPM |
|--------------|-------------|-----------|
| 95% | 3.9% | ~39,000 |
| 99% | 0.80% | ~8,000 |
| 99.9% | 0.08% | ~800 |
| 99.99% | 0.008% | ~80 |

覆盖率从 95% 提到 99.9%，DPPM 下降近 50 倍，但测试时间、向量存储与测试开发成本也会上升。**没有“免费”的覆盖率**；工程上要根据产品定位、现场更换成本与品牌风险做权衡。对 AI 加速器，单卡失效可能导致整机/集群停机，逃逸成本远高于消费级芯片，因此 SLT 与系统级压力测试更常见。

该公式基于单固定故障等简化假设，不能当作质量保证；它的价值在于说明“覆盖率必须接近 100% 才能把 DPPM 压到低位”。

### 2. 中介层面积与每片晶圆成本

300 mm 晶圆的面积约 70,686 mm²。若中介层面积 2,700 mm²（约 3.3× reticle），理论上每片最多约 26 颗，考虑边缘与矩形排布后通常约 20 颗。若中介层晶圆价格 10,000 美元、良率 70%（**示例假设**），每颗合格中介层约 714 美元：

```
10,000 / (20 × 0.70) ≈ $714
```

这还没算 TSV、凸点、组装与 KGD 测试。中介层从 3.3× 增到 5.5× reticle，面积增加约 1.67 倍，每片可排数下降，缺陷概率上升，成本增长快于面积。**这就是为什么“把更多 HBM 塞进一个封装”不是免费的午餐**，也是 CoWoS-L/混合键合被重视的原因。

### 3. HBM 成本占比为什么高

HBM 的成本由四部分组成：DRAM die、TSV 与堆叠、base die/接口逻辑、测试与封装。公开估算常在 **10–20 美元/GB** 量级，但随世代、容量、合约与供需波动很大（见 [HBM 与 GDDR](../../05-存储层次/notes/08-hbm-and-gddr.md)）。

以 192 GB 为例，按 15 美元/GB 计算约 2,880 美元；若按 10 美元/GB 约 1,920 美元，按 20 美元/GB 约 3,840 美元。**仅 HBM 一项就可能超过两颗大逻辑 die 的成本**。这解释了为什么 HBM 供给、价格周期与堆叠良率会直接影响 AI 加速器的 BOM 与售价，也解释了为什么 HBM4 的 2048-bit 接口、16-Hi 堆叠与混合键合同时推高容量、带宽与封装难度。

### 4. 先进封装为什么是产能瓶颈

先进封装不是标准化的“代工后道”，而是需要专用设备、工艺配方与工程团队的系统工程：

- 大尺寸中介层需要高精度光刻、TSV 填充、CMP 与薄化；
- 大面积组装面临翘曲（Warpage）、CTE 失配、underfill 空洞与热应力；
- 多 die 堆叠需要 KGD、堆叠测试与失效定位；
- 产能扩张周期长，设备交付与良率爬坡都需要时间。

因此，先进封装的“价格”不完全是成本加成，还包含稀缺产能的溢价。TSMC 的 CoWoS 扩产计划与年度资本开支是观察 AI 芯片供给的重要指标；具体数字以其财报与公开路线图为准。

### 5. 芯粒的封装成本临界点

[06 Die 成本](06-die-cost.md) 的示例中，2 × 400 mm² 的硅片成本约 372 美元，比单片 800 mm² 的约 620 美元节省 248 美元。若 chiplet 方案新增的封装、互连、KGD 测试与良率损失超过 248 美元，拆分会得不偿失。

粗略的盈亏平衡条件：

```
ΔC_die_saving > ΔC_package + ΔC_test + ΔC_yield_loss + ΔNRE/Q
```

面积越大、D0 越高，die 侧节省越明显；HBM 越多、互连越密、封装良率越低，封装侧增量越大。**chiplet 不是架构信仰，而是一道随产品、工艺与产量变化的算术题**。UCIe 的凸点间距与带宽密度决定了“拆开之后还连得够不够快”，见 [07 先进封装](../../13-工艺制造与先进封装/notes/07-advanced-packaging.md)。

### 6. 成本模型的边界

- **BOM 不是售价**：还要叠加毛利、物流、库存、质保、渠道与关税；
- **良率不是常数**：封装良率随产量爬坡，早期成本更高；
- **价格随供需波动**：HBM 与先进封装在短缺期溢价明显；
- **测试成本与质量成本互为镜像**：省下的测试费可能变成现场失效与召回；
- **公开估算没有统一口径**：CoWoS、HBM、基板报价多为供应链调研，不能当采购依据。

## 总结

先进 AI 芯片的成本必须按“封装后成品”计算：die、HBM、中介层、基板、凸点、组装、测试与 NRE 缺一不可。KGD 与多 die 良率相乘是封装经济的核心，KGD 从 99.5% 提升到 99.9% 可以把 96 颗 DRAM 的整包良率从约 61% 拉到约 90%。测试成本由测试时间、并行 site 数与机时费率主导，测试覆盖则要用 Williams–Brown 关系与逃逸成本一起权衡。先进封装贵在面积、良率、工艺复杂度、材料与产能，而不只是“工序多”。芯粒是否划算，取决于 die 侧节省能否覆盖封装侧增量；所有数字都应标注示例假设、年份与公开估算口径。
