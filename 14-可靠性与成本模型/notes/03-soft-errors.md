# 03 — 软错误与 SER/FIT

> **软错误（soft error）** 是高能粒子（宇宙射线中子、封装材料中的 α 粒子等）在硅中沉积电荷、把存储单元或逻辑节点的状态翻转的瞬态故障——它不损坏芯片，却会悄悄改写数据，而 **软错误率（Soft Error Rate, SER）** 用 **FIT（Failures In Time）** 计量，1 FIT 等于每 10^9 器件小时发生 1 次失效。

---

## 为什么讲这个

AI 芯片有海量片上静态随机存取存储器（Static Random Access Memory, SRAM）、寄存器文件和高带宽内存（High Bandwidth Memory, HBM）。按 `SPECS.md` §5.1，H100 有 80 GB HBM3、B200 有 192 GB HBM3e，单芯片的存储位数达到 10^12 量级；即使每个 bit 的翻转概率极低，乘上巨大的位数和全年不间断运行时间，也可能变成不可忽视的系统故障率。更麻烦的是，软错误往往**没有报错**：一个被翻转的权重、累加器或控制位可能让推理结果悄悄出错，这就是**静默数据损坏（Silent Data Corruption, SDC）**。

软错误与电迁移、老化不同：它不是磨损，不会随着使用年限累积；今天发生的翻转，明天可能不再发生。因此它的统计口径是“单位时间、单位器件数的失效率”，而不是“寿命”。理解 SER/FIT，才能读懂芯片规格书里的可靠性预算，也才能判断纠错码（Error Correcting Code, ECC）、锁步（lockstep）、擦洗（scrubbing）这些机制到底在防什么。

本篇只讨论单芯片/单器件的软错误物理与防护；整机、集群层的检查点/重试（checkpoint/retry）、作业重跑和容错调度属于系统软件层，不在本篇展开。

---

## 核心概念

### 1. 粒子从哪里来

地面环境的辐射源主要有三类：

1. **宇宙射线中子（cosmic-ray neutrons）**：高能宇宙射线进入大气层后产生强子簇射，中子不带电、穿透力强，是海平面软错误的主要来源；
2. **α 粒子（alpha particles）**：来自封装材料、焊料、模塑料中铀/钍衰变链的杂质；α 粒子射程短，但如果在芯片附近发射，沉积电荷很集中；
3. **热中子（thermal neutrons）**：与 ^10B 等核素发生俘获反应，产生高能粒子；封装和工艺中的硼含量会影响这一项。

海平面中子通量常被引用为 **~13 n/cm²/h** 量级（能量 >1 MeV，公开估算；具体能谱与地理位置有关）。海拔越高，大气屏蔽越少：约 1,500 m 处通量约为海平面的 2 倍，3,000 m 处约 4 倍，民航巡航高度（~10 km）可达海平面的 10^2 量级。这也是为什么高原数据中心和航空电子对 SER 更敏感。

α 粒子方面，低 α 封装材料通常要求极低的发射率（公开资料常以 `<0.001–0.01 α/cm²/h` 量级作为等级指标），但具体限值与测试方法以 JEDEC 标准和供应商数据为准。

### 2. 从粒子击中到比特翻转

粒子穿过硅时，沿径迹激发电子—空穴对。硅中产生一对电子—空穴约需 **3.6 eV** 能量，因此一个 MeV 级粒子可以沉积大量电荷。电荷被 PN 结（PN junction）电场收集（漂移），还会通过漏斗效应和扩散被附近节点收集。若收集到的电荷超过节点的**临界电荷（critical charge, Qcrit）**，存储单元的双稳态就会被打破，bit 翻转。

Qcrit 的粗略表达式是：

```
Qcrit ≈ C_node · Vdd
```

节点电容越小、电源电压越低，Qcrit 越小，越容易被翻转。先进工艺的电源电压降到 0.6–1.2 V（`SPECS.md` §7.1），Qcrit 随之下降；但 FinFET/GAA 的收集体积也变小，两个趋势部分抵消。**不能简单地说“工艺越先进，SER 一定越高或越低”**：单位 bit 的 SER 与单位芯片的 SER 可能朝相反方向变化，必须以具体工艺和测试数据为准。

相关术语要区分：

- **单粒子翻转（Single Event Upset, SEU）**：一个粒子导致一个存储位翻转；
- **多比特翻转（Multiple Bit Upset, MBU）**：一个粒子或一次事件影响多个相邻位；
- **单粒子瞬态（Single Event Transient, SET）**：粒子在组合逻辑中产生一个瞬态脉冲，若被下游触发器采样则成为错误；
- **单粒子锁定（Single Event Latchup, SEL）**：粒子触发寄生晶闸管，形成大电流锁定，可能造成永久损伤；
- **单粒子功能中断（Single Event Functional Interrupt, SEFI）**：粒子导致控制器/状态机进入异常状态，需要复位恢复。

### 3. SER 与 FIT 的定义

**FIT（Failures In Time）** 是失效率单位：

```
1 FIT = 1 次失效 / 10^9 器件小时
```

若某器件的失效率为 `λ`（单位 FIT），则其平均无故障时间近似为：

```
MTTF = 10^9 / λ   （小时）
```

软错误通常用 **FIT/bit**、**FIT/Mbit** 或 **FIT/chip** 表示。三者不能混用：`1 FIT/Mbit` 的 SRAM 和 `1 FIT/chip` 的处理器，规模差了几个数量级。

示例（示例假设，工程估算，不构成验收依据）：某 SRAM 的 SER 为 `1 FIT/Mbit`，芯片有 `1 Gbit = 1,000 Mbit`，则芯片级软错误率约 `1,000 FIT`，对应 `MTTF = 10^9 / 1,000 = 10^6` 小时，约 114 年。这个数字只说明“位数放大”的威力，不代表任何真实产品的 SER；实际值必须由 JESD89 类测试和工艺数据给出。

对很小的失效率，时间 `t` 内至少发生一次错误的概率为：

```
P_fail(t) = 1 − exp(−λt) ≈ λt    （当 λt ≪ 1）
```

注意 `λ` 的单位要与 `t` 匹配：若 `λ` 用 FIT，`t` 用小时，则 `λt` 要除以 `10^9`。

### 4. 影响 SER 的因素

| 因素 | 影响方向 | 说明/口径（年份） |
|------|----------|-------------------|
| 海拔 | 越高 SER 越大 | 中子通量随海拔上升；海平面 ~13 n/cm²/h 为公开估算 |
| 纬度/太阳活动 | 高纬度、太阳活动低时通量更高 | 公开空间物理数据；工程上取保守包络 |
| 电源电压 | 电压越低，Qcrit 越小，SER 通常越高 | 近阈值/低电压设计需额外关注 |
| 工艺节点 | 单位 bit SER 趋势不一 | FinFET/GAA 收集体积减小；密度上升；以工艺数据为准 |
| 温度 | 影响较弱且机制混合 | 不宜用单一 Arrhenius 外推 SER |
| 存储类型 | SRAM/动态随机存取存储器（DRAM）/触发器/寄存器不同 | SRAM 双稳态、DRAM 电容、锁存器结构各有差异 |
| 封装材料 | 低 α 材料可降低 α 贡献 | 低 α 等级与 JEDEC 测试方法相关 |
| 屏蔽 | 对中子几乎无效；对 α 有一定作用 | 混凝土/铅对高能中子屏蔽有限；α 主要靠封装材料控制 |

### 5. 防护与纠错

| 防护手段 | 开销 | 纠错/检测能力 | 适用与来源（年份） |
|----------|------|----------------|-------------------|
| 奇偶校验（parity） | 每字 1 bit，面积/延迟很低 | 检测奇数个 bit 错误；不纠错 | 总线、缓存标签（cache tag）、低风险存储；经典教材 |
| 单错纠正/双错检测（Single Error Correction, Double Error Detection, SECDED）ECC（如 72,64） | 64 bit 数据加 8 bit 校验，约 12.5% 额外位 | 纠正 1 bit，检测 2 bit | SRAM/DRAM/缓存（cache）；JEDEC/工业实践 |
| Chipkill / 符号 ECC | 需要按 DRAM 器件组织符号，控制器更复杂 | 可纠正整个 DRAM 芯片失效 | 服务器内存；公开工业方案 |
| 片内 ECC（on-die ECC） | 存储阵列内额外校验位与逻辑 | 在 die 内纠正一定位数的错误 | HBM/DDR5 等；`SPECS.md` §8.1 |
| 系统 ECC | 控制器/链路级校验与重试 | 纠正传输/存储路径错误 | HBM + 系统 ECC 组合；`SPECS.md` §8.1 |
| 双模冗余/三模冗余（Dual/Triple Modular Redundancy, DMR/TMR） | 2× / 3× 面积与功耗 | DMR 检测；TMR 可纠正一个副本 | 安全关键、航天；经典容错设计 |
| 锁步（Lockstep） | 双核/双模块同步，约 2× 面积 | 检测不一致；配合重试可恢复 | 汽车、航天；工业实践 |
| 擦洗（Scrubbing） | 周期性读/写回，占带宽 | 防止错误累积，配合 ECC 使用 | 大容量存储；系统级 |
| 位交错（interleaving） | 布局/布线开销 | 把同一字的位分散，降低 MBU 命中同一字 | ECC 设计；公开文献 |
| 加固单元（如双互锁存储单元 Dual Interlocked Storage Cell, DICE） | 约 2× 面积，速度/功耗代价 | 降低 SEU 截面 | 高可靠 SRAM/寄存器；经典论文 |

ECC 不是万能的：SECDED 只能纠正 1 bit，若一个粒子造成同一字内 2 bit 翻转（MBU），就只能检测而不能纠正；因此需要**物理位交错**把同一逻辑字的位分散到不同存储体（bank）/区域，并配合 scrubbing 防止错误累积。HBM 的片内 ECC 与系统 ECC 是两层防线：前者在堆栈内部处理存储阵列错误，后者覆盖控制器、链路和系统级路径；具体实现随 HBM 代际和厂商而变，见 [05-08 HBM 与 GDDR](../../05-存储层次/notes/08-hbm-and-gddr.md)。

### 6. 关键参数速查

| 参数 | 典型值/范围 | 口径 | 来源（年份） |
|------|-------------|------|--------------|
| 海平面中子通量 | ~13 n/cm²/h | 能量 >1 MeV 量级；随海拔/纬度变化 | 公开估算；JESD89B（2021） |
| FIT 定义 | 1 次失效 / 10^9 器件小时 | 失效率单位 | `SPECS.md` §8.1 |
| Qcrit | 亚 fC 至数 fC 量级 | 依节点电容与电源电压 | 公开文献量级 |
| SECDED 额外开销 | ~12.5%（72,64） | 8 个校验位 / 64 个数据位 | 工业实践；JEDEC/教材 |
| HBM ECC | 片内 ECC + 系统 ECC | 两层防线，非单一机制 | `SPECS.md` §8.1 |
| 低 α 封装材料 | `<0.001–0.01 α/cm²/h` 量级 | 材料等级与测试方法相关 | 公开资料；供应商数据 |

```
     │   SRAM cell         │
     │   ┌─────┐ ┌─────┐   │
     │   │ 1   │ │ 0   │   │  ← 双稳态
     │   └─────┘ └─────┘   │

     └─────────┬───────────┘
               │ 漂移 + 漏斗 + 扩散
               ▼
        收集电荷 Q_coll
               │
        Q_coll > Qcrit ?
          ├─ 否 → 无错误
          └─ 是 → 节点翻转（SEU）
```

说明：粒子并不是“直接写 0 或 1”，而是沉积电荷；只有当收集电荷超过节点临界电荷时，反馈环路才会翻到另一个稳态。

### 图 2：失效率曲线与软错误“地板”

```
失效率
  │ 婴儿期        稳定期          磨损失效
  │  \           ────────          /
  │   \         ─────────        /
  │    \       ───────────      /
  │     ──────软错误贡献──────
  └──────────────────────────────→ 时间
```

软错误在稳定期表现为一个近似恒定的失效率“地板”，不随使用时间累积；这与电迁移/老化等磨损型机制不同。浴盆曲线的婴儿期和磨损期由制造缺陷与老化机制主导，软错误只是稳定期的一部分。

## 深入理解

### 1. 临界电荷与收集效率

把 Qcrit 写成 `C·V` 只是量级估算。真实节点还受以下因素影响：

- **收集体积**：粒子径迹附近的耗尽区、阱和衬底会收集电荷；FinFET 的鳍很薄，收集体积小，但密集布局会让相邻器件共享电荷；
- **漏斗效应（funneling）**：粒子径迹改变电场分布，使更多电荷被收集；
- **寄生双极放大**：在 SRAM 中，粒子可能触发寄生 NPN/PNP 晶体管，放大收集电荷；
- **电荷共享（charge sharing）**：一个粒子可能同时影响相邻多个节点，造成 MBU；
- **节点电容**：先进节点的电容很小，Qcrit 可能只有飞库仑（fC）量级。示例（工程估算）：`C=1 fF`、`Vdd=0.8 V`，则 `Qcrit≈0.8 fC`；而 `1 fC` 约等于 `1 fC / 1.602×10^-19 C ≈ 6,240` 个电子电荷，沉积电荷与 Qcrit 处于同一量级，翻转并不罕见。

### 2. FIT 的统计与外推

FIT 是速率单位，不是概率。若失效率恒定，`t` 时间内失效数服从泊松分布；在 `λt ≪ 1` 时，`P≈λt`。实验上通常用加速测试（中子束、α 源）测出截面，再按能谱/通量外推到现场环境；JEDEC JESD89 系列规定了测试、报告和外推的最低要求。

外推时要特别小心：

- **能谱不同**：加速中子束的能谱与海平面不同，不能只用一个“总通量”比例；
- **几何/角度**：封装、金属层和入射角会改变到达敏感体积的粒子数；
- **多位翻转**：加速测试若只统计单 bit，会低估 MBU；
- **工艺批次**：不同批次的掺杂、尺寸和缺陷密度会改变 SER。

### 3. ECC 的数学与开销

以 SECDED（72,64）为例：64 位数据加 8 位校验，汉明距离为 4，可以纠正 1 位错、检测 2 位错。额外存储开销是 `8/64 = 12.5%`，还要加上编码/解码逻辑的延迟和面积。对 SRAM 来说，ECC 还会影响读写路径、时序和功耗；对 HBM 来说，片内 ECC 会占用存储阵列和带宽预算。

ECC 的纠错能力与“错误是否落在同一个码字”强相关。若物理布局把同一码字的位放在相邻单元，一个粒子造成的 MBU 可能直接击穿 SECDED；因此**位交错**与 ECC 必须一起设计。scrubbing 则负责在错误累积到不可纠之前把它清掉，代价是周期性占用内存带宽。

### 4. 逻辑软错误与屏蔽

组合逻辑也会被粒子击中，但并非每个 SET 都会变成系统错误。错误要“存活”到被采样，需要同时满足：

- **电气屏蔽**：脉冲幅度足够大、宽度足够宽，能传过下游门；
- **逻辑屏蔽**：脉冲到达时，下游门的其他输入使其不敏感；
- **时序屏蔽**：脉冲没有落在触发器的建立/保持窗口内。

因此，逻辑 SER 的估算比 SRAM 复杂得多，需要门级/寄存器传输级仿真和波形传播分析。触发器、锁存器和时钟网络本身也是敏感节点，不能只盯着 SRAM。

### 5. 先进工艺与 AI 芯片

先进工艺让单 bit 的 Qcrit 下降，但 FinFET/GAA 的收集体积、接触栅极结构和金属化也在变化；公开研究对“单位 bit SER 随节点如何变化”并没有单一结论。可以确定的是：

- **密度效应**：同样面积的芯片容纳更多 bit，芯片级 SER 可能上升；
- **3D 堆叠**：HBM 的 TSV、微凸点和堆叠 die 改变了粒子输运与热环境，SER 评估需要针对堆栈；
- **低电压/近阈值**：Qcrit 降低，SER 通常更敏感；
- **AI 负载**：大模型训练对数值错误的容忍度、checkpoint 频率和重算成本，决定了系统愿意为 ECC/重试付出多少开销。

系统层的 checkpoint/retry、作业重跑和集群级容错不在本篇范围；本篇只强调：芯片级的 SER/FIT 预算是这些系统机制设计的输入之一。

---

## 总结

软错误是粒子沉积电荷导致的瞬态比特翻转，不是磨损，也不会永久损坏芯片；其发生率用 SER 描述、用 FIT 计量，1 FIT 等于每 10^9 器件小时 1 次失效。Qcrit 随电压和节点电容下降，海拔、工艺、存储类型和封装材料都会影响 SER；芯片级 SER 还会被海量 bit 数放大。防护靠奇偶校验、SECDED、Chipkill、片内/系统 ECC、TMR/lockstep、位交错和 scrubbing 的组合；所有 SER/FIT 数字都必须来自 JESD89 类测试和工艺数据，示例数字仅为工程估算，不构成验收依据。
