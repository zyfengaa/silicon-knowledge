# 02 — 热循环与机械应力

> 芯片和封装由热膨胀系数（Coefficient of Thermal Expansion, CTE）不同的材料拼成，每次升温、降温都会让它们在彼此约束下产生应变，而反复的**热循环（thermal cycling）** 把这种应变变成焊点、硅通孔（Through-Silicon Via, TSV）、界面和低介电常数（low-k）介质的疲劳裂纹——它不会立刻坏，却决定了封装在产品生命周期里能不能扛住数十万次量级的功率起落（工程估算）。

---

## 为什么讲这个

现代 AI 芯片不是一个“硅片加外壳”的简单结构：大裸片（die）、高带宽内存（High Bandwidth Memory, HBM）堆叠、2.5D 中介层（interposer）、Cu 柱/微凸点（micro-bump）、有机基板、模塑料（mold compound）和散热盖被压在一起，每种材料的 **热膨胀系数（CTE）** 相差数倍。按 `SPECS.md` §1，H100 SXM 的 TDP 为 700 W、B200 为 1,000 W、B300/GB300 为 1,400 W；如此高的功率在训练负载下会反复升降，封装内部每天都在经历“升温—保温—降温”的循环。

热循环失效与电迁移（见 [01 电迁移](01-electromigration.md)）不同：电迁移由电流直接驱动，热循环由**温度变化**驱动；电迁移的典型失效是空洞/小丘，热循环的典型失效是焊点疲劳裂纹、TSV 凸出、界面分层和翘曲。两者又会在高功率封装里耦合：裂纹让电阻上升，局部发热更严重，热应力进一步集中。

本篇聚焦芯片—封装—基板这一层的热机械可靠性；整机风道、液冷回路和机房温度控制属于系统/基础设施层，不在本篇展开。机械冲击、跌落和板级表面贴装（Surface Mount Technology, SMT）焊接也不在本篇范围。

---

## 核心概念

### 1. CTE 失配与热应变

**热膨胀系数（CTE）** 定义为单位温度变化下的相对长度变化：

```
α = (1/L) · (dL/dT)
```

当两种材料被粘在一起、温度变化 `ΔT` 时，若界面不允许自由滑动，它们的自由膨胀量之差会被约束成应变：

```
Δε ≈ Δα · ΔT
```

`Δα` 是两种材料的 CTE 之差。对薄膜/薄片受基底约束的情形，双轴应力常用近似：

```
σ ≈ E · Δα · ΔT / (1 − ν)
```

其中 `E` 是杨氏模量，`ν` 是泊松比。这个式子说明：**CTE 差越大、温差越大、材料越硬，应力越大**。硅的 CTE 只有约 2.6 ppm/K，而 Cu 约 17 ppm/K、有机基板约 15–18 ppm/K；把它们在 200 °C 以上的回流焊温度下粘在一起，再冷却到室温，界面就会积累可观的剪切应变。

### 2. 材料 CTE 与模量

| 材料 | CTE（ppm/K，室温附近） | 杨氏模量（GPa） | 口径/来源（年份） |
|------|------------------------|-----------------|------------------|
| 硅（Si） | ~2.6 | ~130（各向异性，约 130–190） | 教材与公开材料数据 |
| 铜（Cu） | ~16.5–17.5 | ~110–130 | 公开材料数据 |
| SAC305 无铅焊料 | ~21–24 | ~30–50（随温度变化） | JEDEC/IPC 公开资料 |
| 有机基板（BT/ABF） | 面内 ~15–18；面外可达 40–60 | 面内 ~20–25 | 公开估算；强各向异性 |
| 模塑料（mold compound） | ~8–12 | ~10–25 | 公开估算；配方相关 |
| 底部填充（underfill） | ~20–30 | ~5–10 | 公开估算；配方相关 |

### 3. 热循环疲劳与 Coffin–Manson

焊点在热循环中经历塑性/蠕变变形，属于**低周疲劳（low-cycle fatigue）**。描述其寿命的经典关系是 **Coffin–Manson 方程（Coffin–Manson relation）**：

```
N_f = C · (Δε_p)^(-m)
```

`N_f` 是失效前的循环数，`Δε_p` 是塑性应变幅，`m` 是疲劳指数。对 SnAgCu 焊料，公开文献常取 `m ≈ 1.8–2.2`；工程上常用 `m≈2` 做量级估算。`C` 是材料/结构相关的常数，不能跨封装形式直接套用。

对倒装焊/球栅阵列，焊点的剪切应变常用**到中性点距离（Distance to Neutral Point, DNP）** 估算：

```
Δγ ≈ L_D · Δα · ΔT / h
```

`L_D` 是焊点到封装中性点的距离，`h` 是焊点高度。这个式子的直觉是：离中性点越远，热膨胀差累积得越多；焊点越矮，同样的位移被“挤”成越大的剪切应变。示例（工程估算，不构成验收依据）：`L_D=5 mm`、`Δα=14.4 ppm/K`、`ΔT=100 K`、`h=100 µm`，得到 `Δγ≈7.2%`——已经远超焊料的弹性范围，必然进入塑性/蠕变。

当需要同时考虑循环频率和最高温度时，常用 **Norris–Landzberg 模型（Norris–Landzberg model）**：

```
N_f = C · (ΔT)^(-n) · f^m · exp(Ea / kT_max)
```

常见取值 `n≈1.9`、`m≈1/3`、`Ea≈0.1 eV`（公开文献量级）。它说明：除了温差，**升降温速率/频率** 和 **最高温度** 也会改变寿命——快速循环让每次循环的蠕变时间变短，寿命通常更长；而更高的 `T_max` 会加速蠕变和氧化。

### 4. 失效模式与薄弱环节

热循环失效通常从应力集中处开始：

- **焊点疲劳**：裂纹沿焊料/金属间化合物（Intermetallic Compound, IMC）界面或焊料内部扩展，表现为菊花链电阻逐渐上升；Cu 柱、微凸点、球栅阵列（Ball Grid Array, BGA）焊球都可能失效；
- **TSV 凸出/开裂**：Cu 的 CTE 远大于 Si，温度升高时 TSV 轴向膨胀，把周围 Si 和后道工序（Back End of Line, BEOL）顶起；反复循环可导致界面分层或 Si 裂纹；
- **低 k 介质分层**：低 k 材料机械强度低，CTE 与 Cu/衬垫不匹配，容易在 BEOL 界面产生裂纹；
- **芯片粘接/散热界面退化**：芯片粘接（die attach）、热界面材料（Thermal Interface Material, TIM）、焊料 TIM 在循环中疲劳或分层，热阻上升，结温进一步升高；
- **翘曲与共面性**：封装在回流温度下可能“笑脸/哭脸”变形，影响 SMT 贴装、HBM 堆叠和混合键合对准；
- **密封/盖板失效**：盖板粘接、密封圈在循环中开裂，导致湿气侵入。

### 5. 翘曲与界面强度

**翘曲（warpage）** 是 CTE 失配在宏观尺度上的表现。die、基板、模塑料和盖板的热膨胀不一致，封装在温度变化时弯曲；即使没有开裂，翘曲也会让后续工艺（贴片、回流、键合）超出对准窗口。薄膜应力常用 **Stoney 公式（Stoney equation）** 估算：

```
σ_f = E_s · h_s² / [6 · (1 − ν_s) · R · h_f]
```

`E_s`、`h_s`、`ν_s` 是基底模量、厚度和泊松比，`R` 是曲率半径，`h_f` 是薄膜厚度。实际封装更复杂，通常用阴影云纹（Shadow Moiré）、数字图像相关（DIC）或有限元仿真测量/预测。

界面强度同样关键：Cu/介质、Cu/焊料、IMC/焊料、模塑料/基板等界面的粘附能有限，热循环会驱动分层裂纹沿最薄弱环节（weakest link）扩展。JEDEC 的湿度/回流等级（如 J-STD-020）和温度循环标准（JESD22-A104）就是用来在受控条件下暴露这些薄弱环节的。

### 6. 热管理对可靠性的影响

热管理不仅决定性能，也直接决定热机械寿命：

- **降低 `Tj`** 会减慢 Arrhenius 型老化（见 [04 老化](04-aging-bti-hci.md)），但不一定减小 **温差**；如果功耗波动很大，`ΔT` 仍可能很大；
- **功率循环（power cycling）** 与 **温度循环（temperature cycling）** 不同：前者由芯片自身发热驱动，后者由环境/设备温度变化驱动；两者的循环波形、驻留（dwell）时间和失效模式都不同；
- **液冷/冷板** 降低峰值温度，却可能让封装在“冷启动—满载—降载”之间经历更大的瞬态梯度；冷却液温度与流量控制属于系统层，不在本篇展开；
- **TIM 退化** 会形成正反馈：热阻上升 → `Tj` 上升 → 老化/蠕变加速 → 界面进一步退化。

按 [11-03 功耗、能效与芯片热设计](../../11-系统分析与性能工程/notes/03-power-thermal.md)，芯片结温常见设计上限约 85–105 °C（依器件与寿命预算而定）。这个上限本身就是热机械与器件老化共同约束的结果，而不是一个孤立的温度数字。

```
   └──────────────────────────────┘

   ┌──────────────────────────────┐
   │  基板（CTE ≈ 15–18 ppm/K）    │  伸长多
   └──────────────────────────────┘
        ←── 离中性点越远，位移差越大 ──→
```

中性点通常在封装中心附近；位于角落的焊点承受最大的相对位移，因此焊点疲劳裂纹常从最外圈/最远角开始。

### 图 2：Coffin–Manson 的 log–log 直线

```
log N_f
   │\
   │ \        斜率 = −m
   │  \
   │   \
   │    \
   └──────────────→ log Δε_p
```

在双对数坐标下，`N_f = C·(Δε_p)^(-m)` 是一条直线。`m≈2` 意味着塑性应变翻倍，寿命约降到 1/4；这就是“温差大一点，寿命差很多”的数学来源。

### 图 3：热循环的加载波形

```
温度
  ↑
  │     ┌────────┐
  │    /          \        ┌────────┐
  │   /            \      /          \
  │  /              \    /            \
  └─/────────────────\──/──────────────\──→ 时间
    ramp   dwell   ramp  ramp   dwell
```

`ramp` 速率、驻留时间和循环次数共同决定蠕变/疲劳的累积。JEDEC 温度循环标准会规定温变速率、驻留时间和循环数，以便不同实验室的结果可比。

## 深入理解

### 1. 从应变到裂纹

焊点的热机械响应可以粗略分成三个阶段：

1. **弹性阶段**：应变小于屈服应变，应力随温度线性变化；
2. **塑性/蠕变阶段**：焊料在高温下持续蠕变，应力松弛，每次循环积累不可逆变形；
3. **裂纹萌生与扩展**：在应力集中处（IMC 界面、焊点颈部、孔洞附近）萌生微裂纹，裂纹沿界面或焊料扩展，直到有效承载面积不足。

失效判据通常是电阻上升一定比例或完全开路。由于裂纹扩展是随机的，实验数据常用威布尔分布（Weibull distribution）描述；`β` 形状参数反映失效机理的集中程度，`η` 尺度参数反映特征寿命。

### 2. 加速因子与寿命外推

用 Coffin–Manson 做温度循环加速时，若只改变温差：

```
AF ≈ (ΔT_stress / ΔT_use)^m
```

示例（工程估算，不构成验收依据）：`m=2`，实验 `ΔT=150 K`、使用 `ΔT=100 K`，则 `AF=(1.5)^2=2.25`；实验 1,000 循环约对应使用 2,250 循环。若再叠加 Norris–Landzberg 的频率和最高温度项，加速因子会更大。实际外推必须确认失效机理不变：如果实验温度高到触发焊料熔化、IMC 异常长大或模塑料降解，外推就失去意义。

### 3. 封装结构如何“对抗”CTE 失配

工程上有几条常见路线：

- **材料匹配**：选择 CTE 更接近 Si 的基板/中介层（如陶瓷、玻璃、硅中介层），或用填料调节模塑料 CTE；
- **柔性连接**：用 underfill 分散焊点应变，用 compliant joint、Cu 柱/焊料帽组合吸收位移；
- **结构约束**：加 stiffener、lid、背板，把翘曲压在设计窗口内；
- **几何优化**：增大焊点高度 `h`、缩短 DNP、优化焊点布局，直接降低 `Δγ`；
- **工艺控制**：控制回流曲线、固化制度、残余应力，避免“出厂就带着裂纹”。

这些手段都有代价：underfill 增加工艺步骤和返修难度，stiffener 增加重量和成本，CTE 匹配材料可能更贵或更难加工。可靠性设计本质上是在性能、成本、可制造性之间做权衡。

### 4. 先进封装中的新问题

2.5D/3D 封装把热机械问题推到更极端：

- **HBM 堆叠**：多层 DRAM 与 TSV、微凸点、underfill 叠加，任一层界面开裂都可能让整个堆栈失效；HBM 的高带宽也意味着高功耗密度，局部 `ΔT` 更大；
- **混合键合（hybrid bonding）**：Cu–Cu 直接键合没有焊料缓冲，对表面平整度、颗粒、CTE 失配和退火温度极其敏感；热循环会在键合界面产生应力集中；
- **大尺寸中介层**：CoWoS 级中介层面积大，与基板/盖板的 CTE 失配在角落放大，翘曲控制成为良率关键；
- **芯片—封装协同设计**：热、力、电必须联合仿真，单看芯片或单看封装都会漏掉耦合效应。

具体封装结构与路线图数字见 [13-04 后道工序 BEOL](../../13-工艺制造与先进封装/notes/04-beol.md)；本篇只保留热机械可靠性的通用物理与模型。

### 5. 与电迁移、老化的耦合

热循环与电迁移、BTI/HCI 不是独立事件：

- 裂纹/分层让局部热阻上升，`Tj` 升高，电迁移和老化加速；
- 电迁移造成的空洞/小丘改变局部应力，可能诱发裂纹；
- 热循环中的高温阶段加速 BTI/HCI 的缺陷生成；
- 封装翘曲改变芯片与散热器的接触，进一步影响温度。

因此，产品级可靠性预算需要把多个机制的加速因子乘在一起，并用最坏情况的热—电—力剖面做联合评估。任何单一机制的“通过”都不等于产品可靠。

---

## 总结

热循环失效的根源是 CTE 失配：温度变化让不同材料产生不相等的膨胀，界面和焊点被迫吸收应变，反复循环后疲劳开裂。Coffin–Manson 用 `N_f ∝ (Δε_p)^-m` 描述低周疲劳，DNP 公式把封装几何与剪切应变联系起来，Norris–Landzberg 进一步加入频率和最高温度。工程上靠材料匹配、underfill、结构约束、几何优化和工艺控制来延长寿命；所有寿命/加速因子数字都是工程估算，不构成验收依据。
