# 05 — 良率模型：面积、缺陷密度与分布

> 一句话结论：**良率（Yield）不是固定常数，而是随裸片（Die）面积 A 与缺陷密度 D0 指数衰减的统计结果；Poisson、Murphy 与负二项模型给出同一趋势下的三种估计，是判断大 die 经济性的第一道计算。**

## 为什么讲这个

芯片的经济性从晶圆开始：对同一产品与合约，一片 300 mm 晶圆的价格基本固定，能切出多少颗合格 die，决定了每颗 die 分摊到的制造成本。面积翻倍不仅让每片晶圆的 die 数近似减半，还让每颗 die 碰到致命缺陷的概率上升，因此**成本随面积超线性增长**。这解释了两个现象：GPU 计算 die 通常停在约 800 mm² 量级，接近一个掩模版（Reticle）视场；更大的逻辑芯片转向芯粒（Chiplet）与先进封装。

良率模型也是理解高带宽内存（HBM）、基板上晶圆上芯片封装（CoWoS）与已知合格 die（Known Good Die, KGD）的基础。堆叠与 2.5D 封装把多颗 die 的良率相乘，任何一颗 die 的缺陷都会放大为整包损失。工艺与封装背景见 [05 工艺节点](../../13-工艺制造与先进封装/notes/05-process-nodes.md)、[07 先进封装](../../13-工艺制造与先进封装/notes/07-advanced-packaging.md) 与 [HBM 与 GDDR](../../05-存储层次/notes/08-hbm-and-gddr.md)。

集群层的采购、TCO 与 $/GPU-hour 不在本篇范围，见 [why-ai-cluster](https://github.com/zyfengaa/why-ai-cluster/blob/main/README.md)。

## 核心概念

### 1. 良率有多个口径

工程上说的“良率”至少包含以下几层，不能混用：

- **晶圆测试良率（Wafer Sort Yield）**：晶圆级探针测试通过的 die 比例，本篇的主要对象。
- **封装良率（Package Yield）**：切割、贴装、键合、塑封、基板组装后仍合格的比例，见 [07 封装与测试成本](07-packaging-test-cost.md)。
- **终测良率（Final Test Yield）**：封装完成后的最终测试通过率。
- **参数良率（Parametric Yield）**：功能和速度达标、但电压/频率/功耗落在不同档位的比例；通过分档（Binning）变成不同 SKU。
- **系统良率（System Yield）**：整卡或整机级别的通过率，还叠加互连、供电与散热。

完整良率可近似写成 `Y_total ≈ Y_random × Y_systematic × Y_parametric`。这是工程近似，不是严格独立事件；本篇聚焦**随机缺陷限制的 die 良率**。

### 2. 缺陷密度 D0

**缺陷密度（Defect Density, D0）** 定义为单位面积内的致命缺陷数，单位是 defects/cm²。SPECS §8.2 给出的典型量级是 **~0.1–1 defects/cm²**，属于成熟工艺的公开估算。

需要注意三点：

1. **不是所有缺陷都致命**。颗粒落在空旷区域可能无害，落在栅氧、金属间距或通孔上才导致短路/开路；因此引入临界面积。
2. **D0 是分层、分工艺、分成熟度的**。光刻、刻蚀、沉积、化学机械抛光（CMP）各环节都有缺陷来源，晶圆厂通常按层追踪，而不是只报一个总数。
3. **D0 随产量爬坡下降**。同一节点在风险试产（Risk Production）与大规模量产（HVM）阶段的 D0 可差数倍，这是良率学习曲线（Yield Ramp）的核心。

### 3. 泊松模型（Poisson Model）

假设缺陷在晶圆上完全随机、彼此独立，且每颗 die 上出现 k 个缺陷服从泊松分布，则零缺陷概率为：

```
Y_poisson = exp(-A · D0)
```

其中 A 为 die 面积（cm²），D0 为缺陷密度（defects/cm²）。这是最简单的模型，适合 A·D0 较小（小 die、低缺陷密度）的情形。对大 die，它通常**偏悲观**，因为它忽略了缺陷成团：团簇会让一部分 die 报废，却让更多 die 完全干净。

### 4. 墨菲模型（Murphy Model）

Murphy 假设缺陷密度在晶圆上不是常数，而是呈三角形分布（峰值在 D0、范围约 0–2D0），再对 `exp(-A·D)` 积分，得到：

```
Y_murphy = ((1 - exp(-A·D0)) / (A·D0))^2
```

它用分布的非均匀性修正了 Poisson 的过度悲观，是大 die 时代最常用的解析模型之一。注意：不同教材对 Murphy 分布假设的表述略有差异，但公式与 SPECS §8.2 一致。

### 5. 负二项模型（Negative Binomial Model）

若缺陷密度 D 本身服从 Gamma 分布（均值 D0、形状参数 α），对泊松良率做混合积分，得到：

```
Y_nb = (1 + A·D0/α)^(-α)
```

**α 是缺陷团簇参数（Clustering Parameter）**：

- α → ∞ 时，Gamma 分布退化为常数，公式回到 Poisson；
- α = 1 时，`Y = 1/(1 + A·D0)`；
- α 越小，缺陷越成团，同样平均 D0 下**大 die 的良率越高**（因为很多 die 一个缺陷也没有）。

负二项模型在 HBM、大容量存储和大型系统级芯片（SoC）的良率估算中用得很多；它把“缺陷成团”这一物理事实写进了一个可调参数。

### 6. 临界面积（Critical Area）

更物理的写法是：

```
Y = exp(-A_c · D0)
```

**临界面积（Critical Area, A_c）** 是“给定缺陷尺寸分布下，缺陷落上去会导致失效的等效面积”。A_c 小于物理面积 A，且依赖版图：

- 金属线间距越小，短路型缺陷的 A_c 越大；
- 通孔/接触越多，开路型缺陷的 A_c 越大；
- 缺陷尺寸分布越偏向大颗粒，A_c 越大。

因此提升良率不只靠“把 die 做小”，还可以靠**设计可制造性（Design for Manufacturing, DFM）**：放宽关键间距、增加冗余通孔、优化 CMP 密度、避免天线效应（Antenna Effect）。

### 7. 缺陷团簇与空间效应

**缺陷团簇（Defect Clustering）** 指缺陷在空间上聚集，破坏泊松模型的独立同分布假设。它在晶圆图上通常表现为：

- 边缘环状缺陷（Edge Ring）：边缘排除区附近工艺均匀性差；
- 划痕/条纹（Scratch/Streak）：CMP 或清洗引入；
- 局部热点（Hot Spot）：光刻/刻蚀的局部偏移；
- 随机点缺陷：颗粒污染，最接近泊松假设。

团簇之外还有**系统良率损失**（光刻热点、设计规则边缘、静态随机存取存储器（SRAM）良率限制）和**参数良率损失**（速度/漏电不达标）。这些都无法用单一 D0 解释。

### 8. 关键参数与口径

| 参数 | 取值/范围 | 口径 | 来源/年份 |
|------|----------|------|----------|
| die 面积 A | ~100–800 mm² | 逻辑 die，依产品 | 公开产品资料/示例 |
| 缺陷密度 D0 | ~0.1–1 defects/cm² | 成熟工艺量级 | SPECS §8.2 |
| 团簇参数 α | ~0.5–5 | 工程拟合值，非公开工艺参数 | 公开文献/示例假设 |
| 晶圆直径 D | 300 mm | 主流量产晶圆 | SPECS §7.2 |
| 掩模版视场 | 26 × 33 mm（~858 mm²） | 单次曝光视场 | SPECS §7.2 |

> 上表中的 α 是拟合参数，不同产品、不同层、不同缺陷类型差异很大；不存在“某个节点的标准 α”。

| 模型 | 公式 | 核心假设 | 适用场景 | 主要局限 |
|------|------|----------|----------|----------|

| 负二项 | `Y = (1+A·D0/α)^(-α)` | 缺陷密度 Gamma 分布、成团 | 大 die、存储阵列、HBM | α 需拟合，外推需谨慎 |

## 深入理解

### 1. Poisson 公式从哪来

把每颗 die 看成一个面积为 A 的区域，缺陷到达是强度为 D0 的泊松过程。落入该区域的缺陷数 K 满足：

```
P(K = k) = (A·D0)^k · exp(-A·D0) / k!
```

良率要求 K = 0，因此 `Y = P(K=0) = exp(-A·D0)`。这个推导只用到“独立、稀有、平均密度恒定”三个条件；一旦缺陷成团，第三个条件就被破坏。

### 2. Gamma 混合如何产生负二项

设每颗 die 所在位置的局部缺陷密度为 D，D 服从 Gamma 分布：

```
D ~ Gamma(shape = α, rate = α/D0)
```

先对给定 D 取泊松零缺陷概率 `exp(-A·D)`，再对 D 的 Gamma 分布积分，得到：

```
Y = E[exp(-A·D)] = (1 + A·D0/α)^(-α)
```

这就是负二项名称的来源：混合后的缺陷计数服从负二项分布。α 越小，Gamma 分布越“尖”，局部密度差异越大，团簇越明显。

### 3. 数字示例：大 die 的模型分歧

取 A = 8 cm²、D0 = 0.3 defects/cm²：

- Poisson：`exp(-2.4) = 9.1%`；
- Murphy：`((1 - exp(-2.4))/2.4)² ≈ 14.4%`；
- 负二项 α=2：`(1 + 1.2)^(-2) ≈ 20.7%`；
- 负二项 α=1：`1/(1 + 2.4) ≈ 29.4%`。

同一片晶圆、同一个平均 D0，估算出的良率可以从 9% 到 29%，对应每颗合格 die 的成本相差三倍以上。因此，**良率模型不是学术装饰，而是直接进入成本模型的输入**。

### 4. 面积弹性：为什么大 die 这么贵

对 Poisson 模型，忽略边缘损失时，每片晶圆的毛 die 数近似与 1/A 成正比，于是每颗合格 die 的成本：

```
C_good ∝ A · exp(A·D0)
```

对 ln C_good 求导：

```
∂ ln C_good / ∂ ln A = 1 + A·D0
```

- A = 8 cm²、D0 = 0.1 时，弹性约为 1.8：面积增加 10%，每颗合格 die 成本约增加 18%；
- A = 8 cm²、D0 = 0.3 时，弹性约为 3.4：面积增加 10%，成本约增加 34%。

这就是“die 越大越贵”的定量版本。它也是芯粒的经济动机：把 800 mm² 拆成两颗 400 mm²，单颗 die 的良率显著提高，但代价是封装、互连与测试成本，详见 [06 Die 成本](06-die-cost.md) 与 [07 封装与测试成本](07-packaging-test-cost.md)。

### 5. 模型之外：良率是一个分布，不是一个数

真实晶圆有中心-边缘差异、批间差异、机台差异。工程上更可靠的做法是：

1. 用晶圆图（Wafer Map）检查空间模式，先区分随机缺陷与系统缺陷；
2. 用多模型区间而不是单点估算成本，例如“Poisson 悲观值 / 负二项基准值”；
3. 把良率学习曲线纳入产品生命周期，而不是假设量产第一天就是成熟良率；
4. 用测试与冗余修复把“可修复缺陷”从致命缺陷中移出。

存储阵列是第 4 点的典型：DRAM/HBM 通过冗余行/列与激光/电熔丝修复，把原始 bit 良率提升到可用水平；但修复能力有限，且修复测试本身有成本。这正是 KGD 与先进封装成本的前置条件。

## 总结

良率由 die 面积、缺陷密度与缺陷空间分布共同决定，Poisson 给出最悲观的下界，Murphy 与负二项通过分布假设修正大 die 的估算。D0 的公开量级是 0.1–1 defects/cm²，但真实值随工艺、层与成熟度变化，必须标注口径。面积弹性 `1 + A·D0` 说明大 die 的成本增长快于面积本身，这是芯粒与良率修复的经济动机。任何良率数字都应带模型、D0、面积与年份，否则不可比较。
