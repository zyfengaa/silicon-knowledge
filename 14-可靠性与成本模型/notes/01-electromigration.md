# 01 — 电迁移：导线为什么会“断”

> **电迁移（Electromigration, EM）** 是高电流密度下金属原子被电子流“推着走”的扩散过程——原子在阴极侧留下空洞、在阳极侧堆成小丘，最终把互连“饿断”或“挤短”，而 Black 方程把寿命写成电流密度与温度的函数，是互连签核（signoff）的第一性工具。

---

## 为什么讲这个

晶体管开关一次只需皮秒级，但为它输送电荷的金属线要在整个产品寿命里持续承受电流。先进工艺把互连截面越做越小，**后道工序（Back End of Line, BEOL）** 的电流密度反而上升；按 `SPECS.md` §1 的口径，H100 SXM 的热设计功耗（Thermal Design Power, TDP）为 700 W、B200 为 1,000 W、B300/GB300 为 1,400 W，在 0.6–1.2 V 级供电电压下，单芯片供电电流可达数百至上千安培量级（工程估算）。这些电流最终要经过电源网格、通孔和局部信号线，电迁移因此从“封装厂才关心的问题”变成芯片设计签核的硬约束。

电迁移的可怕之处在于**慢**：它不会让芯片上电即坏，而是在几年尺度上逐渐累积，等空洞长到足以开路时，产品已经出货。可靠性工程师必须在设计阶段用加速实验和模型回答两个问题：这条线在额定电流与结温下能活多久？设计规则还留有多少余量？

本篇只讨论芯片内互连与通孔的电迁移；焊点、微凸点和硅通孔（TSV）的电迁移属于封装可靠性，见 [04 后道工序 BEOL](../../13-工艺制造与先进封装/notes/04-beol.md) 与 [02 热循环与机械应力](02-thermal-mechanical-stress.md)。机柜级供配电不在本篇范围。

## 核心概念

### 1. 电子风力与原子迁移

金属中的电流由电子定向漂移形成。电子在电场中加速，又与晶格、缺陷和杂质碰撞，把动量交给金属原子；宏观上表现为一个与电子漂移方向相同的力，称为**电子风力（electron wind force）**。单位体积的驱动力可写成：

```
F_em = Z* · e · E
```

其中 `Z*` 是**有效电荷数（effective charge number）**，`e` 是元电荷，`E` 是电场。Cu 的 `Z*` 公开文献常给出 -1 至 -5 的量级，符号表示原子被推向电子漂移方向（即常规电流的反方向）。

原子迁移的总通量还要减去**背应力（backstress）** 的贡献。原子在阴极侧堆积、在阳极侧耗尽，会建立应力梯度，把原子往回推：

```
J_a = (C·D / kT) · (Z*·e·E - Ω·∂σ/∂x)
```

`C` 是原子浓度，`D` 是扩散系数，`Ω` 是原子体积，`σ` 是静水应力。当电子风力压过背应力时，净原子流把质量从阴极搬到阳极：阴极形成**空洞（void）**，阳极形成**小丘（hillock）**。空洞长到贯穿线宽或击穿衬垫层，互连就开路；小丘则可能顶破钝化层或与相邻线短路。

扩散路径决定激活能：晶格扩散、晶界扩散、表面扩散和界面扩散的 `Ea` 不同。现代 Cu 互连上方有介质帽层、侧面有 Ta/TaN 衬垫，界面扩散往往主导，因此 `Ea` 对工艺、衬垫和帽层非常敏感。`SPECS.md` §8.1 给出的 Cu 互连 `Ea` 为 **~0.8–1.2 eV**，是公开文献量级，不是某一家工艺设计套件（Process Design Kit, PDK）的保证值。

### 2. Black 方程

**Black 方程（Black's equation）** 是电迁移寿命最常用的经验模型：

```
MTTF = A · J^(-n) · exp(Ea / kT)
```

- `MTTF`：中位失效时间（mean time to failure），单位通常为小时；
- `A`：与金属体系、线宽、长度、晶粒结构、衬垫和失效判据有关的经验常数；
- `J`：电流密度；
- `n`：电流密度指数，`SPECS.md` §8.1 取 **n ≈ 1–2**；
- `Ea`：激活能，Cu 互连 **~0.8–1.2 eV**；
- `k`：玻尔兹曼常数，`8.617×10^-5 eV/K`；
- `T`：绝对温度，单位 K。

`n` 不是普适常数：它随失效阶段（空洞形核、空洞长大、衬垫击穿）和实验窗口变化，工程上按 1–2 取值并在工艺数据上校准。`A` 更是“把几何与材料都塞进去”的拟合量，不能把一篇论文的 `A` 直接搬到另一种工艺。

方程的两个指数项给出两条设计直觉：

1. **电流密度翻倍**：`n=1` 时寿命减半，`n=2` 时寿命降到 1/4；
2. **温度升高**：寿命按 Arrhenius 规律指数下降。取 `Ea=1.0 eV`，结温从 100 °C 升到 125 °C（373 K → 398 K），寿命约降到 `exp(1.0/8.617e-5 × (1/373 − 1/398)) ≈ 7` 分之一。这是工程估算，不构成验收依据。

### 3. 电流密度、温度、线宽与通孔

| 参数 | 典型值/范围 | 对 MTTF 的影响 | 口径/来源（年份） |
|------|-------------|----------------|------------------|
| 电流密度 `J` | 加速实验常见 10^6 A/cm² 量级；签核限值由工艺设计套件（Process Design Kit, PDK）给出 | `MTTF ∝ J^-n`，是最强的设计杠杆 | 公开文献量级；PDK 为准 |
| 电流指数 `n` | 1–2 | 决定“加电流”惩罚有多重 | `SPECS.md` §8.1 |
| Cu 激活能 `Ea` | 0.8–1.2 eV | 决定温度敏感性；每 20–25 °C 可差数倍 | `SPECS.md` §8.1；公开文献 |
| 结温 `Tj` | 常见设计上限约 85–105 °C | 指数影响寿命，且与自热耦合 | [11-03 热设计](../../11-系统分析与性能工程/notes/03-power-thermal.md) |
| 线宽/长度 | 窄线、短线；Blech 长度以下可“免疫” | 晶粒结构与背应力改变失效模式 | 公开文献；工艺相关 |
| 通孔 | 单孔/冗余孔、孔底电流拥挤 | 孔底空洞是常见失效点 | PDK 与工艺数据 |
| 衬垫/帽层 | Ta/TaN、Co/Ru、介质帽层 | 决定主导扩散路径与 `Ea` | 公开文献；路线图口径 |
| 电流波形 | 直流（DC）最坏；交流（AC）有恢复/平均效应 | 单向电流的净原子输运最大 | JEDEC JEP122H（2016） |

**温度**不仅来自环境，还来自焦耳自热（Joule self-heating）：电流在电阻上产生的热量让局部温度高于芯片平均温度，而更高的温度又加速扩散，形成正反馈。因此电迁移签核必须使用“最坏情况电流 + 最坏情况局部温度”的组合，而不是芯片平均功耗对应的温度。

**线宽**的影响不是单调的。窄线可能形成“竹节状”（bamboo）晶粒结构，晶界路径减少，寿命反而提高；但当线宽小到界面扩散主导时，衬垫与帽层质量成为关键。**通孔**则是几何上的电流拥挤点：孔底拐角处电流密度最高，空洞常从那里形核。冗余通孔、加大通孔包围（enclosure）、在孔下加金属“储层”都是常见设计手段。

### 4. Blech 长度与“不死”线

**Blech 效应（Blech effect）** 指出：当线足够短时，阳极侧积累的原子产生的背应力足以抵消电子风力，净原子流为零，线不会发生电迁移失效。判据通常写成电流密度与长度的乘积：

```
j · L < (j · L)_c   →   无净漂移（“immortal”）
```

临界积 `(j·L)_c` 随金属体系、衬垫和界面而变，公开文献报道的量级为 `10^3–10^4 A/cm`。举例：若 `(j·L)_c = 4,000 A/cm`、`j = 10^6 A/cm²`，则临界长度约 `4,000 / 10^6 cm = 40 µm`（示例假设，工程估算）。这解释了为什么标准单元内部很短的一段线通常不是电迁移瓶颈，而长电源干线、跨模块总线和通孔链才是。

Blech 效应不是“免死金牌”：它依赖阳极侧有足够的金属储层，且空洞形核仍可能发生；在 AC 或脉冲电流下，净质量输运还会被部分恢复。设计规则会把 Blech 长度作为“短线豁免”的依据，但不会把它推广到所有互连。

### 5. 设计规则与签核

电迁移签核通常包含以下动作：

- **分层电流密度上限**：不同金属层、不同线宽、不同通孔类型有各自的 `J_max`，由 PDK 给出；
- **通孔规则**：冗余通孔、孔阵列、孔底 enclosure、避免单孔承载大电流；
- **电源网格分析**：电压降（IR drop）与电迁移联合分析，因为电压降会改变局部电流分布；
- **温度感知**：使用封装热模型和功耗图，而不是统一的 25 °C 或 85 °C；
- **AC/DC 区分**：单向 DC 最坏，双向 AC 可用平均电流或恢复因子修正；
- **寿命目标**：常见产品目标为 10 年量级，但具体目标由产品规格与客户要求决定；所有寿命数字均为工程估算，不构成验收依据；
- **工艺校准**：用加速实验提取 `n`、`Ea` 和分布参数，不能只套教科书常数。

在先进节点，Cu 的电阻率因尺寸效应上升，衬垫占截面比例增大，互连可靠性与性能的矛盾更突出。Co、Ru、Mo 等替代金属和势垒层工程仍在路线图阶段，量产导入节奏与具体工艺相关，应以代工厂公开路线图为准。

### 图 1：空洞与小丘的形成

```
        常规电流 I  ←────────────────────────
        电子流 e⁻   ────────────────────────→
        原子流      ────────────────────────→  （电子风力）
       ┌────────┐                              ┌────────┐
       │  空洞   │======= Cu 互连 =============│  小丘   │
       └────────┘                              └────────┘
         阴极 (-)                                阳极 (+)
        质量耗尽                                质量堆积
```

说明：电子从阴极流向阳极，原子被电子风力推向同一方向，因此在阴极侧留下空洞、在阳极侧堆出小丘。实际失效点常位于通孔底部、衬垫界面或晶界三叉点。

### 图 2：log MTTF 与 1/T

```
log MTTF
   │\
   │ \       斜率 = Ea / k
   │  \
   │   \
   │    \
   └──────────────→ 1/T
     高温          低温
```

在 Black 方程中，`ln(MTTF)` 对 `1/T` 作图应得到直线，斜率是 `Ea/k`。实验上若多个温度点不共线，说明失效机制发生了变化（例如从晶界扩散转为界面扩散），不能把一条直线外推到所有温度。

### 图 3：Blech 长度判据

```
j
↑
│  失效区：j·L > (j·L)c
│  ┌──────────────────────
│  │
│  │  免疫区：j·L < (j·L)c
│  └──────────────────────→ L
        L_B = (j·L)c / j
```

短线落在“免疫区”内，长线落在“失效区”。设计规则中的“短线豁免”本质上是在利用这条边界。

## 深入理解

### 1. 从原子漂移到电阻失效

电迁移失效不是瞬间开路，而是一条“酝酿—形核—长大—击穿”的链：

1. **孕育期**：原子流开始造成局部浓度变化，但空洞尚未形成；
2. **空洞形核**：当局部应力或空位过饱和达到临界值，空洞在通孔底部、晶界或界面处形核；
3. **空洞长大**：空洞沿电流方向扩展，有效导电截面减小，电阻缓慢上升；
4. **失效**：空洞贯穿线宽、衬垫被击穿或局部熔断，电阻跳变或开路。

常见失效判据是电阻漂移达到 10% 或完全开路，具体阈值以 JEDEC 标准或客户规范为准。由于失效是随机过程，实验得到的是**寿命分布**而不是一个确定值。工程上常用对数正态分布描述 `t50` 和 `σ`；芯片上有海量互连，最早失效的那一小部分决定产品失效率，因此“中位寿命”不等于“没有早期失效”。

### 2. 加速实验与外推

典型实验在高电流密度和高温度下 stress 一批结构，定期测电阻，记录失效时间，再用 Black 方程外推到使用条件。加速因子可写成：

```
AF = (J_stress / J_use)^n · exp[(Ea/k) · (1/T_use − 1/T_stress)]
```

示例（工程估算，不构成验收依据）：`J_stress = 5×J_use`、`n=2`，电流项贡献 25×；`T_stress = 125 °C`、`T_use = 100 °C`、`Ea = 1.0 eV`，温度项约 7×；合计约 175×。若实验在 1,000 小时得到失效，粗略对应使用条件约 `1,000 × 175 = 175,000` 小时，约 20 年。这个数字只用于说明量级，真实外推还要考虑焦耳自热、电流拥挤、Blech 效应和分布尾部。

### 3. 与电压降（IR drop）、热和机械应力的耦合

电迁移从来不是孤立机制：

- **电压降（IR drop）** 改变局部电压和电流分布，电源网格的“热点”往往也是电迁移热点；
- **焦耳自热** 抬高局部温度，而温度又加速扩散；
- **背应力** 来自钝化层、衬垫和封装约束，会影响原子回流的强度；
- **热迁移（thermomigration）** 在温度梯度下也会驱动原子迁移，与电迁移叠加；
- **低 k 介质** 机械强度较低，空洞和小丘更容易造成分层或开裂。

因此，先进节点的可靠性签核越来越强调“电—热—力”联合仿真，而不是单独跑一条电迁移规则。

### 4. 封装与先进封装中的电迁移

芯片内的 Cu 互连只是电迁移的一半故事。倒装焊的焊料凸点、微凸点、Cu 柱和 TSV 同样承载高电流密度，且它们的扩散系数、熔点与界面金属间化合物（IMC）行为与 BEOL 完全不同。AI 芯片的大电流、高带宽内存（High Bandwidth Memory, HBM）堆叠和 2.5D 中介层（interposer）让这些封装级互连成为新的瓶颈；其失效模式与测试方法见 [13-04 BEOL 与封装](../../13-工艺制造与先进封装/notes/04-beol.md)。

一个常见的系统级连锁是：供电电流上升 → 局部焦耳热上升 → 焊点/TSV 热应力上升 → 微裂纹 → 电阻上升 → 局部热得更厉害。可靠性设计必须把这条正反馈回路切断，而不是只优化某一个环节。

---

## 总结

电迁移的本质是电子风力把金属原子从阴极搬到阳极，空洞导致开路、小丘导致短路；Black 方程用 `J^-n` 和 Arrhenius 项把寿命与电流密度、温度联系起来。Cu 互连的 `Ea` 约为 0.8–1.2 eV、`n` 约为 1–2，具体数值必须由工艺数据校准。设计上靠电流密度上限、通孔冗余、Blech 短线豁免和电—热联合签核来控制风险；所有寿命外推都是工程估算，不构成验收依据。
