# 14 可靠性与成本模型习题

> 覆盖 14 模块八个主题：Black 方程、热循环疲劳、SER/FIT/ECC、老化外推、良率模型、die 成本与 NRE、封装/测试成本、TCO 与 $/token。
> 所有数字均为**示例假设或工程估算，不构成采购、报价或验收依据**；答题先写公式，再代数，最后说明假设。

## 一、Black 方程与互连寿命

### 题目

某 Cu 互连在 `J0 = 1×10^6 A/cm²`、`T0 = 100 °C` 下 `MTTF0 = 10,000 h`。取 `MTTF = A·J^-n·exp(Ea/kT)`，`n = 2`、`Ea = 1.0 eV`、`k = 8.617×10^-5 eV/K`。
（1）求 `J = 2×10^6 A/cm²`、`T = 125 °C` 的 MTTF。（2）求使用条件（`5×10^5 A/cm²`、85 °C）到加速条件（`2×10^6 A/cm²`、125 °C）的加速因子；1,000 h 实验对应多少年？（3）取 `(j·L)_c = 5,000 A/cm`，求 `j = 2×10^6 A/cm²` 的 Blech 临界长度。

### 答案要点

1. 电流项 `(2)^-2 = 1/4`；温度项 `exp[11605×(1/373.15−1/398.15)] = exp(1.953) ≈ 7.05`；`MTTF = 10,000/(4×7.05) ≈ 355 h`。

2. `AF_J = (2e6/5e5)^2 = 16`；`AF_T = exp[11605×(1/358.15−1/398.15)] ≈ 25.9`；`AF ≈ 415`。1,000 h 约对应 `4.15×10^5 h ≈ 47` 年；外推假设机制不变，未计自热与 Blech 效应。

3. `L_c = 5,000/2×10^6 cm = 25 µm`。短于该长度可能因背应力“免疫”，但依赖阳极储层。补充：仅升 10 °C（100→110 °C），寿命约 `exp(0.80) ≈ 2.2` 分之一。

## 二、CTE 失配与热循环疲劳

### 题目

倒装焊中焊点到中性点距离 `L_D = 5 mm`，`Δα = 15 ppm/K`，焊点高度 `h = 100 µm`，`ΔT = 80 K`。
（1）用 `Δγ ≈ L_D·Δα·ΔT/h` 估算剪切应变。（2）取 Coffin–Manson `N_f = C·(Δγ)^-m`、`m = 2`，已知 `Δγ = 2%` 时 `N_f = 10,000`，求该工况寿命。（3）实验 `ΔT = 150 K`、使用 `80 K`，求加速因子；1,000 次实验对应多少次使用？（4）焊点高度增到 150 µm，寿命提高多少倍？

### 答案要点

1. `Δγ = 5e-3 × 15e-6 × 80 / 100e-6 = 6%`，已远超弹性范围，必然进入塑性/蠕变。

2. 由 `10,000 = C×0.02^-2` 得 `C = 4`；`N_f = 4/0.06² ≈ 1,111` 次。按每天 2 次循环约 1.5 年，仅为示例，真实寿命取决于驻留时间与焊料体系。

3. `AF ≈ (150/80)^2 = 3.52`；1,000 次实验约对应 3,520 次使用循环。叠加 Norris–Landzberg 的频率/最高温度项会更大，但需确认失效机制未变。

4. `Δγ ∝ 1/h`，`N_f ∝ h²`，`(150/100)^2 = 2.25` 倍。代价是封装高度与工艺复杂度上升。

## 三、SER、FIT 与 ECC

### 题目

某 GPU 有 `4 Gbit` 片上 SRAM，原始 SER 为 `0.5 FIT/Mbit`。
（1）求芯片级 FIT 与 MTTF。（2）1,000 张 GPU 的集群，求整集群失效率、MTBF 与 30 天内至少一次软错误的概率。（3）ECC 把有效错误率降低 1,000 倍，重算概率。（4）SECDED（72,64）的存储开销是多少？为何遇到同字内 2-bit 翻转只能检测？

### 答案要点

1. `4 Gbit = 4,000 Mbit`；`SER = 0.5×4,000 = 2,000 FIT`；`MTTF = 10^9/2,000 = 5×10^5 h ≈ 57` 年。

2. 集群 `2×10^6 FIT = 2×10^-3/h`，`MTBF = 500 h`；30 天 `λt = 2×10^-3×720 = 1.44`，`P = 1−e^-1.44 ≈ 76.3%`。“至少一次”不等于“每次可见故障”。

3. `λ = 2×10^-6/h`，`λt = 1.44×10^-3`，`P ≈ 0.144%`。ECC 压低事件率三个数量级，但仍需 scrubbing 防止错误累积。

4. `8/64 = 12.5%`；192 GB HBM 按此估算需额外 24 GB 物理容量（示例价约 $360）。SECDED 汉明距离为 4，可纠 1 bit、检 2 bit，但无足够校验位定位 2 bit；需位交错、更强 ECC 或重试。

## 四、BTI/HCI 老化外推

### 题目

pMOS 的 NBTI 退化 `ΔVth = A·t^n`，`n = 0.2`；1,000 h 后 `ΔVth = 20 mV`。
（1）外推到 10 年（87,600 h）。（2）取 `α = 1.3`、`Vdd = 0.9 V`、`Vth = 0.35 V`，用 `ΔD/D ≈ α·ΔVth/(Vdd−Vth)` 估算延迟退化。（3）取 `Ea = 0.1 eV`，求 125 °C 应力相对 85 °C 使用的 AF；1,000 h 应力对应多少使用小时？（4）关键路径 BOL 500 ps，老化 +11.6%，电压/温度余量 +8%，时钟 620 ps，是否满足？老化 +15% 呢？

### 答案要点

1. `ΔVth = 20×(87,600/1,000)^0.2 = 20×87.6^0.2 ≈ 49 mV`。

2. `ΔD/D ≈ 1.3×0.049/(0.9−0.35) ≈ 11.6%`。实际敏感度取决于门类型、摆幅与负载。

3. `AF = exp[(0.1/8.617e-5)(1/358.15−1/398.15)] ≈ exp(0.326) ≈ 1.39`；1,000 h 仅对应约 1,390 h。BTI 温度加速很弱，老化实验常靠升压、延长应力或 on-the-fly 测量。

4. `500×1.116×1.08 ≈ 603 ps < 620 ps`，满足，余量约 2.9%。老化 15% 时 `500×1.15×1.08 ≈ 621 ps > 620 ps`，不满足；需降频、调压（会加速老化）或电路补偿。

## 五、四种良率模型

### 题目

`A = 6 cm²`，`D0 = 0.25 defects/cm²`，负二项 `α = 2`，临界面积 `A_c = 0.7A`。
（1）用 Poisson、Murphy、负二项与临界面积模型算良率并排序。（2）Poisson 下良率降到 10% 的 `D0`。（3）Poisson 的面积弹性 `∂ln C_good/∂ln A`；面积 +10% 时成本增加多少？（4）拆成 3 颗 2 cm² die，硅片侧成本约省多少？还须考虑什么？

### 答案要点

1. `A·D0 = 1.5`：Poisson `e^-1.5 = 22.3%`；Murphy `((1−e^-1.5)/1.5)^2 = 26.8%`；负二项 `(1+0.75)^-2 = 32.7%`；临界面积 `e^-1.05 = 35.0%`。排序：临界面积 > 负二项 > Murphy > Poisson；临界面积模型用 `A_c < A` 修正，不能与物理面积口径混用。

2. `e^-6D0 = 0.1` → `6D0 = ln10 = 2.303` → `D0 ≈ 0.384 defects/cm²`。

3. 弹性 `= 1+A·D0 = 2.5`；面积 +10% 使每颗合格 die 成本约 +25%。`1` 来自毛 die 数反比于面积，`A·D0` 来自良率指数衰减。

4. 2 cm² 良率 `e^-0.5 = 60.7%`；以 `A/Y` 为代理，单片 `6/0.223 = 26.9`，3 小片 `3×2/0.607 = 9.89`，约省 63%。但须加封装、die-to-die 互连、KGD 测试与堆叠良率损失，净收益可能远小于硅片侧。

## 六、Die 成本与 NRE

### 题目

300 mm 晶圆（`D = 30 cm`），`e = 0.3 cm`，`A = 8 cm²`，晶圆 `$18,000/片`，`D0 = 0.15`，Poisson 良率，NRE `$120M`，`Q = 500,000`。
（1）求毛 die 数、良率、每颗合格 die 成本。（2）加 NRE 摊销后的完全成本与盈亏平衡产量（ASP `$6,000`、变动成本 `$1,400`）。（3）`D0` 翻倍到 0.3 的成本。（4）面积增到 10 cm² 的成本变化。

### 答案要点

1. `N_gross ≈ π×14.7²/8 − π×30/√16 = 84.86−23.56 ≈ 61`；`Y = e^-1.2 = 30.1%`；`N_good ≈ 18.45`；`C ≈ 18,000/18.45 ≈ $976/颗`。

2. `NRE/颗 = 120M/500k = $240`；完全成本约 `$1,216`。`Q_breakeven = 120M/(6,000−1,400) ≈ 26,100` 颗；低于此产量 NRE 摊不平。

3. `Y = e^-2.4 = 9.07%`；`N_good ≈ 5.56`；`C ≈ $3,237/颗`，约为原来的 3.3 倍。D0 是最强杠杆之一。

4. `N_gross ≈ π×14.7²/10 − π×30/√20 = 67.9−21.1 ≈ 46.8`；`Y = e^-1.5 = 22.3%`；`N_good ≈ 10.4`；`C ≈ $1,724/颗`，约 +76%。面积 +25% 而成本 +76%，即面积弹性。

## 七、封装与测试成本

### 题目

2.5D 封装含 2 颗逻辑 die（各 `$976`）、8 个 24 GB HBM3E（`$15/GB`）、中介层与组装 `$900`、基板 `$180`、测试 `$300`、封装 NRE `$50`，封装良率 88%。
（1）求封装后单颗成本。（2）8 个 12-Hi HBM 共 96 颗 DRAM；KGD 99.5%、组装 99%、终测 99.5%，求整包良率；KGD 99.9% 呢？（3）探针 45 s、`$180/h`、12 site；终测 120 s、`$120/h`、8 site；SLT 2,400 s、`$60/h`、1 site，求各自成本。（4）`Y = 55%`，用 Williams–Brown `DL ≈ 1−Y^(1−T)` 求覆盖率 99% 与 99.9% 的 DPPM。

### 答案要点

1. `2×976 + 8×24×15 + 900 + 180 + 300 + 50 = $6,262`；`C = 6,262/0.88 ≈ $7,116/颗`。

2. `0.995^96 ≈ 0.618`；`0.618×0.99×0.995 ≈ 60.9%`。KGD 99.9%：`0.999^96 ≈ 0.908`；×0.99×0.995 ≈ 89.5%。KGD 提升 0.4 个百分点，整包良率提升近 30 个百分点。

3. 探针 `180×45/(3600×12) ≈ $0.19/die`；终测 `120×120/(3600×8) ≈ $0.50/颗`；SLT `60×2,400/3,600 = $40/颗`。SLT 是大头，测试时间是最强杠杆。

4. `DL(99%) = 1−0.55^0.01 ≈ 0.596% ≈ 5,960 DPPM`；`DL(99.9%) ≈ 0.0598% ≈ 598 DPPM`。覆盖率从 99% 到 99.9%，DPPM 降约 10 倍，但测试时间与向量成本上升，须与逃逸成本权衡。

## 八、TCO 与 $/token

### 题目

某 GPU 的 capex `$24,000`，寿命 5 年，`U = 75%`，年固定运维 `$1,300`，`P_IT = 1.2 kW`，`PUE = 1.25`，空闲功率比 `i = 0.3`，电价 `$0.09/kWh`。
（1）求 $/busy GPU-hour；并重算 `U = 50%` 与 90%。（2）推理每 GPU 250 token/s 时 $/M token；500 与 100 token/s 呢？（3）70B 模型训练 10T token，512 张 H100（989 TFLOPS BF16 dense），MFU 40%，求 GPU-hours、天数、总成本与 $/M token。（4）电价 `$0.05→$0.20` 与利用率 `75%→50%`，哪个影响更大？

### 答案要点

1. `busy h = 5×8760×0.75 = 32,850`；capex `24,000/32,850 ≈ 0.731`；固定 `1,300/(8760×0.75) ≈ 0.198`；电费 `1.2×1.25×[0.3+0.7×0.75]/0.75×0.09 ≈ 0.149`；合计 `≈ $1.08/h`。`U=50%` 时约 `$1.57/h`；`U=90%` 时约 `$0.91/h`。

2. `$/M token = C_hourly×10^6/(3600×R_tok)`：250 token/s → `1.08e6/0.9e6 ≈ $1.20/M`；500 → `$0.60/M`；100 → `$3.00/M`。吞吐翻倍，$/token 减半。

3. 每 GPU 有效算力 `989e12×0.4 = 3.956e14 FLOP/s`；总 FLOPs `6×70e9×10e12 = 4.2e24`；`GPU-hours = 4.2e24/3.956e14/3600 ≈ 2.95e6`；天数 `2.95e6/512/24 ≈ 240`；成本 `≈ $3.19M`；`$/M token ≈ 3.19e6/10e6 ≈ $0.319/M`。不含重跑、数据管道与人力。

4. 电价项从 `0.083` 到 `0.33`，TCO 约 `1.01→1.26`（+25%）；利用率 75%→50% 从 `1.08` 到 `1.57`（+45%）。本例中利用率更敏感；电价极高或寿命更长时可能反转，必须做敏感性分析。
