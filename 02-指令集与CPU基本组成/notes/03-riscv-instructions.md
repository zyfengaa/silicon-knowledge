# 模块 02：指令集与 CPU 基本组成
## 03 — RV32I 指令格式与常用指令

### RV32I 格式概述

所有 RV32I 指令长度均为 32 位，并对齐到 4 字节边界。操作码（opcode）占据位 [6:0]，并决定指令格式。共有六种核心格式：

```
R-type:   | funct7[31:25] | rs2[24:20] | rs1[19:15] | funct3[14:12] | rd[11:7] | opcode[6:0] |
I-type:   | imm[31:20]              | rs1[19:15] | funct3[14:12] | rd[11:7] | opcode[6:0] |
S-type:   | imm[11:5][31:25]| rs2[24:20]| rs1[19:15]| funct3[14:12]| imm[4:0][11:7]| opcode|
B-type:   | [12|10:5][31:25]| rs2[24:20]| rs1[19:15]| funct3[14:12]| [4:1|11][11:7]| opcode|
U-type:   | imm[31:12]                                        | rd[11:7] | opcode[6:0] |
J-type:   | imm[20|10:1|11|19:12]                            | rd[11:7] | opcode[6:0] |
```

### 字段详解

| 字段       | 位          | 用途                                                       |
|------------|-------------|------------------------------------------------------------|
| opcode     | [6:0]       | 主操作码；用于标识指令类别                                 |
| rd         | [11:7]      | 目的寄存器（由运算写入）                                   |
| funct3     | [14:12]     | 3 位操作码修饰字段                                         |
| rs1        | [19:15]     | 第一个源寄存器操作数                                       |
| rs2        | [24:20]     | 第二个源寄存器操作数                                       |
| funct7     | [31:25]     | 7 位操作码修饰字段（R 型）                                 |
| imm        | 视格式而定  | 立即数；对 I/S/B/J 类型进行符号扩展，而 U 类型放置 imm[31:12] |

### 逐格式解析

#### R 型（寄存器型）

用于对两个寄存器（register）操作数执行算术/逻辑运算。

```
31          25|24   20|19   15|14      12|11     7|6       0
+------------+--------+--------+----------+--------+---------+
|  funct7    |  rs2   |  rs1   |  funct3  |   rd   | opcode  |
|  7 bits    | 5 bits | 5 bits |  3 bits  | 5 bits | 7 bits  |
+------------+--------+--------+----------+--------+---------+
```

**示例 `add x1, x2, x3`**：`x1 = x2 + x3`
- opcode = 0110011 (0x33)
- rd = x1 = 00001
- funct3 = 000
- rs1 = x2 = 00010
- rs2 = x3 = 00011
- funct7 = 0000000

编码后的二进制：`0000000 00011 00010 000 00001 0110011`

十六进制：`0x003100B3`

#### I 型（立即数型）

用于立即数算术、加载（load）和 JALR。立即数（immediate）字段会进行符号扩展（sign-extend）。

```
31                              20|19   15|14      12|11     7|6       0
+--------------------------------+--------+----------+--------+---------+
|              imm               |  rs1   |  funct3  |   rd   | opcode  |
|            12 bits             | 5 bits |  3 bits  | 5 bits | 7 bits  |
+--------------------------------+--------+----------+--------+---------+
```

**示例 `addi x1, x2, -5`**：`x1 = x2 + (-5)`
- opcode = 0010011 (0x13)
- rd = x1 = 00001
- funct3 = 000
- rs1 = x2 = 00010
- imm = -5 = 111111111011（12 位二进制补码）

编码后的二进制：`111111111011 00010 000 00001 0010011`

十六进制：`0xFFB10093`

#### S 型（存储型）

用于存储（store）指令。为保持操作码编码统一，立即数被拆分到两个位段中。

```
31           25|24   20|19   15|14      12|11        7|6       0
+-------------+--------+--------+----------+-----------+---------+
|  imm[11:5]  |  rs2   |  rs1   |  funct3  | imm[4:0]  | opcode  |
|   7 bits    | 5 bits | 5 bits |  3 bits  |  5 bits   | 7 bits  |
+-------------+--------+--------+----------+-----------+---------+
```

**示例 `sw x1, 8(x2)`**：`Mem[x2 + 8] = x1`
- opcode = 0100011 (0x23)
- funct3 = 010
- rs1 = x2 = 00010
- rs2 = x1 = 00001
- imm[11:5] = 0000000（8 的第 11:5 位）
- imm[4:0] = 01000（8 的第 4:0 位）

二进制：`0000000 00001 00010 010 01000 0100011`

十六进制：`0x00112423`

#### B 型（分支型）

用于条件分支（branch）。立即数编码一个带符号的 PC 相对偏移（PC-relative offset）。偏移量的第 0 位始终为 0（指令对齐），因此不存储第 [0] 位。

```
31      30|29          25|24  20|19  15|14  12|11  8|7      |6     0
+---------+--------------+-------+-------+------+-------+-------+-------+
| imm[12] | imm[10:5]    |  rs2  |  rs1  |funct3|imm[4:1]|imm[11]|opcode |
| 1 bit   | 6 bits       | 5 bit | 5 bit |3 bit | 4 bit | 1 bit | 7 bit |
+---------+--------------+-------+-------+------+-------+-------+-------+
```

注意，这个 13 位带符号偏移量的最低有效位是隐含的（始终为 0），因此实际存储的字段是 `imm[12]`、`imm[10:5]`、`imm[4:1]` 和 `imm[11]`。

**示例 `beq x1, x2, label`**（其中标签（label）为 +16 字节 = +4 条指令）：
- opcode = 1100011 (0x63)
- funct3 = 000
- rs1 = x1 = 00001
- rs2 = x2 = 00010
- imm = 16 = 0 000000 1000 0（偏移位 [12|10:5|4:1|11]）

16 的位位置（二进制 000000010000，即仅第 4 位被置位）：
- 第 12 位 = 0，第 10:5 位 = 000000，第 4:1 位 = 1000，第 11 位 = 0
- 因此 imm[12|10:5] = 0|000000 = 0000000
- imm[4:1|11] = 1000|0 = 10000

二进制：`0000000 00010 00001 000 10000 1100011`

十六进制：`0x00208863`

#### U 型（高位立即数型）

用于 LUI（load upper immediate，加载高位立即数）和 AUIPC（add upper immediate to PC，将高位立即数加到 PC）。立即数构成高 20 位；低 12 位为零。

```
31                       12|11     7|6       0
+---------------------------+--------+---------+
|          imm              |   rd   | opcode  |
|        20 bits            | 5 bits | 7 bits  |
+---------------------------+--------+---------+
```

**示例 `lui x1, 0x12345`**：`x1 = 0x12345000`
- opcode = 0110111 (0x37)
- rd = x1 = 00001
- imm = 0x12345 = 00010010001101000101

十六进制：`0x123450B7`

#### J 型（跳转型）

用于 JAL（jump and link，跳转并链接）。立即数编码一个带符号的 PC 相对偏移，其对齐约束与 B 型相同。

```
31            30|29     21|20   19         12|11     7|6       0
+--------------+----------+-------+-------------+--------+---------+
|  imm[20]     | imm[10:1]| imm[11]| imm[19:12] |   rd   | opcode  |
|  1 bit       | 10 bits  | 1 bit  |  8 bits    | 5 bits | 7 bits  |
+--------------+----------+-------+-------------+--------+---------+
```

### 常用 RV32I 指令

#### 算术指令（R 型）

| 助记符   | 操作                          | funct7    | funct3 | opcode |
|----------|-------------------------------|-----------|--------|--------|
| ADD      | rd = rs1 + rs2                | 0000000   | 000    | 0110011|
| SUB      | rd = rs1 - rs2                | 0100000   | 000    | 0110011|
| SLL      | rd = rs1 << rs2[4:0]          | 0000000   | 001    | 0110011|
| SLT      | rd = (rs1 < rs2)（有符号）    | 0000000   | 010    | 0110011|
| SLTU     | rd = (rs1 < rs2)（无符号）    | 0000000   | 011    | 0110011|
| XOR      | rd = rs1 ^ rs2                | 0000000   | 100    | 0110011|
| SRL      | rd = rs1 >> rs2[4:0]          | 0000000   | 101    | 0110011|
| SRA      | rd = rs1 >> rs2[4:0]（算术）  | 0100000   | 101    | 0110011|
| OR       | rd = rs1 | rs2        | 0000000   | 110    | 0110011|
| AND      | rd = rs1 & rs2                | 0000000   | 111    | 0110011|

#### 立即数算术指令（I 型）

| 助记符   | 操作                             | funct3 | opcode |
|----------|----------------------------------|--------|--------|
| ADDI     | rd = rs1 + sext(imm)             | 000    | 0010011|
| SLTI     | rd = (rs1 < sext(imm))（有符号） | 010    | 0010011|
| SLTIU    | rd = (rs1 < sext(imm))（无符号） | 011    | 0010011|
| XORI     | rd = rs1 ^ sext(imm)             | 100    | 0010011|
| ORI      | rd = rs1 | sext(imm)      | 110    | 0010011|
| ANDI     | rd = rs1 & sext(imm)             | 111    | 0010011|
| SLLI     | rd = rs1 << imm[4:0]             | 001    | 0010011|
| SRLI     | rd = rs1 >> imm[4:0]             | 101    | 0010011|
| SRAI     | rd = rs1 >> imm[4:0]（算术）     | 101    | 0010011|

注：对于移位指令，funct7 用于区分 SRLI（0000000）与 SRAI（0100000）。

#### 加载与存储指令

| 助记符   | 操作                              | funct3 | opcode |
|----------|-----------------------------------|--------|--------|
| LB       | rd = sext(M[rs1+imm], 8 位)       | 000    | 0000011|
| LH       | rd = sext(M[rs1+imm], 16 位)      | 001    | 0000011|
| LW       | rd = M[rs1+imm]                   | 010    | 0000011|
| LBU      | rd = zext(M[rs1+imm], 8 位)       | 100    | 0000011|
| LHU      | rd = zext(M[rs1+imm], 16 位)      | 101    | 0000011|
| SB       | M[rs1+imm] = rs2[7:0]             | 000    | 0100011|
| SH       | M[rs1+imm] = rs2[15:0]            | 001    | 0100011|
| SW       | M[rs1+imm] = rs2                  | 010    | 0100011|

加载和存储指令都使用相同的 12 位带符号立即数；加载指令将其放入 I 型的 imm[11:0] 字段，而存储指令将其拆分为 imm[11:5] 和 imm[4:0]。

#### 分支指令（B 型）

| 助记符   | 条件                                        | funct3 | opcode |
|----------|---------------------------------------------|--------|--------|
| BEQ      | 若 (rs1 == rs2)，PC += imm                  | 000    | 1100011|
| BNE      | 若 (rs1 != rs2)，PC += imm                  | 001    | 1100011|
| BLT      | 若 (rs1 < rs2，有符号)，PC += imm           | 100    | 1100011|
| BGE      | 若 (rs1 >= rs2，有符号)，PC += imm          | 101    | 1100011|
| BLTU     | 若 (rs1 < rs2，无符号)，PC += imm           | 110    | 1100011|
| BGEU     | 若 (rs1 >= rs2，无符号)，PC += imm          | 111    | 1100011|

#### 跳转指令（J 型和 I 型）

| 助记符   | 操作                          | opcode |
|----------|-------------------------------|--------|
| JAL      | rd = PC+4; PC += imm          | 1101111|
| JALR     | rd = PC+4; PC = rs1 + imm     | 1100111|

`jal x1, func` 将返回地址保存在 x1 中并跳转。
`jalr x0, x1, 0` 返回（x0 丢弃结果，x1 保存返回地址）。

#### 高位立即数指令（U 型）

| 助记符   | 操作                            | opcode |
|----------|---------------------------------|--------|
| LUI      | rd = imm << 12                  | 0110111|
| AUIPC    | rd = PC + (imm << 12)           | 0010111|

### 编码练习

**练习 1**：编码 `addi x5, x6, 100`
- opcode = 0010011
- rd = x5 = 00101
- funct3 = 000
- rs1 = x6 = 00110
- imm = 100 = 000001100100（12 位）
- 二进制：`000001100100 00110 000 00101 0010011`
- 十六进制：`0x06430293`

**练习 2**：编码 `sub x10, x11, x12`
- opcode = 0110011
- rd = x10 = 01010
- funct3 = 000
- rs1 = x11 = 01011
- rs2 = x12 = 01100
- funct7 = 0100000（用于区分 SUB 与 ADD）
- 二进制：`0100000 01100 01011 000 01010 0110011`
- 十六进制：`0x40C58533`
