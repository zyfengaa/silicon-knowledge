# 03 — 前道工序 FEOL

> 一句话结论：FEOL 把空白晶圆变成 nMOS 与 pMOS；核心是浅沟槽隔离、阱注入、栅堆叠、源漏工程与激活退火，而所有步骤都被同一份有限的热预算约束。

## 为什么讲这个

器件物理回答“MOSFET 为什么能开关”，工艺回答“怎样在硅片上批量做出数百万个参数一致的 MOSFET”。**前道工序（Front-End-of-Line, FEOL）** 就是后者的主体：它决定阈值电压（Vth）、驱动电流、漏电、寄生电阻和器件变异，是芯片性能与良率的第一道关口。

FEOL 的每一步都不是孤立的。栅氧厚度会影响阈值电压，源漏退火会同时激活掺杂和扩散掺杂，侧墙材料会改变寄生电容，硅化物会决定接触电阻。把这些步骤串起来的那条隐形约束，就是**热预算（Thermal Budget）**。

本篇只讲到源漏、硅化物和接触开始的边界；接触之后的金属互连见 [BEOL](04-beol.md)，图形如何定义见 [光刻](02-lithography.md)，器件物理见 [MOSFET 工作原理](../../12-半导体器件与CMOS电路/notes/02-mosfet-operation.md)。集群层面的内容不在本篇范围。

## 核心概念

### 1. 边界与流程总览

FEOL 从清洗后的晶圆开始，典型顺序是：

```
STI 隔离 → 阱/沟道注入 → 栅堆叠 → 栅极图形 → 侧墙
→ 源漏扩展/晕环 → 源漏外延 → 激活退火 → 硅化物 → 接触（MOL）
```

严格说，接触孔和钨塞常被划入**中道工序（Middle-of-Line, MOL）**；它介于 FEOL 与 BEOL 之间，负责把晶体管端接到第一层金属。本笔记把接触作为 FEOL 的收尾一起讨论。

先进节点用鳍式场效应晶体管（FinFET）或环绕栅极（Gate-All-Around, GAA）取代平面栅，但单元操作没有变：仍然是隔离、掺杂、栅介质、栅电极、侧墙、源漏、退火、硅化物。变化的是几何形状、界面工程和工艺顺序。

### 2. 浅沟槽隔离（STI）

**浅沟槽隔离（Shallow Trench Isolation, STI）** 的任务是在硅片上有选择地挖出沟槽并填满绝缘介质，把相邻器件的有源区隔开。

典型步骤：

1. 生长薄垫氧化层（pad oxide，约 5–15 nm），再沉积氮化硅（约 50–150 nm）作为 CMP 停止层和刻蚀硬掩模。
2. 光刻定义有源区，干法刻蚀（反应离子刻蚀，RIE）氮化硅、垫氧化层和硅，形成深约 200–400 nm 的沟槽（公开工艺量级，2010s–2020s）。
3. 侧壁生长一层薄氧化层作为衬里，圆滑沟槽角落、修复刻蚀损伤。
4. 用高密度等离子体化学气相沉积（HDP-CVD）或可流动化学气相沉积（FCVD）填充氧化硅，要求高深宽比下无空洞。
5. 退火致密化，再用化学机械抛光（CMP）以氮化硅为停止层磨平。
6. 去除氮化硅和垫氧化层，得到平面化的有源区与隔离区。

STI 取代了早期的局部氧化隔离（LOCOS）。LOCOS 的“鸟嘴”会侵占有源区，且在细线宽下难以控制；STI 更平坦、更紧凑，但带来了沟槽填充、角落漏电、CMP 碟形凹陷和应力控制等新问题。

### 3. 阱与沟道掺杂

CMOS 需要在同一衬底上做出 n 型和 p 型区域。**阱注入（Well Implant）** 用光刻胶作掩模，分别对 nMOS 区和 pMOS 区做高能离子注入：

- 深阱：能量可达数百 keV 到 1 MeV 量级，形成较深的掺杂背景。
- 逆向阱（retrograde well）：通过多次不同能量的注入，让掺杂浓度在表面附近较低、在深处较高，以抑制闩锁（latch-up）和短沟道效应。
- 沟道注入/穿通阻挡（punchthrough stopper）：调节表面附近的掺杂，控制阈值电压和亚阈值漏电。
- 晕环注入（Halo/Pocket）：在源漏附近做倾斜注入，提高局部掺杂、抑制短沟道效应。

阱浓度通常在 10¹⁷–10¹⁸ cm⁻³ 量级，源漏则在 10²⁰–10²¹ cm⁻³ 量级（公开工艺量级，2010s–2020s）。注入后需要退火修复晶格损伤并激活掺杂；这一步的温度和时间会直接影响后续热预算。

### 4. 栅堆叠：从 SiO₂ 到 High-k / 金属栅

栅堆叠决定栅极对沟道的控制能力。经典结构是热生长 SiO₂ 加多晶硅栅；随着栅氧变薄，直接隧穿漏电迅速上升。解决方案是**高介电常数介质（High-k）+ 金属栅（Metal Gate）**：

- **界面层（Interfacial Layer, IL）**：约 0.5–1 nm 的 SiO₂ 或 SiON，保证与硅的良好界面。
- **高介电常数介质（High-k）**：通常用 HfO₂（k ≈ 20–25），以**原子层沉积（Atomic Layer Deposition, ALD）** 形成 2–3 nm 薄膜。折算成 SiO₂ 的**等效氧化层厚度（Equivalent Oxide Thickness, EOT）** 约 0.8–1.0 nm（公开工艺量级，2010s–2020s），既保持栅控，又降低隧穿漏电。
- **金属栅**：TiN、TaN、TiAl 等多层结构，通过**功函数（Work Function）** 调节 nMOS/pMOS 的阈值电压；有时还用偶极层（dipole）做更精细的 Vth 调节。
- **栅极最后形成（Gate-Last / Replacement Metal Gate, RMG）**：先用牺牲多晶硅做“假栅”，完成源漏注入和高温退火后，再去掉假栅，沉积 High-k 和金属栅。这样 High-k 不必经历源漏激活的高温，避免结晶、界面反应和功函数漂移。

Intel 在 45 nm 节点（2007）首次量产 High-k + 金属栅，是 FEOL 的一个标志性转折。此前的 SiO₂/SiON + 多晶硅体系在 EOT 继续缩小时遇到漏电和耗尽效应瓶颈。

### 5. 栅极图形与侧墙

栅极图形由光刻和干法刻蚀定义。先进节点的栅长常在十几到二十几纳米量级（公开估算，2020s），但“N5/5nm 级、N3/3nm 级”不是栅长，也不是任何一个单一物理尺寸，见 [本模块第 5 篇](05-process-nodes.md) 对工艺节点的讨论。

栅极两侧要形成**侧墙（Spacer）**：

- 偏移侧墙（offset spacer）：很薄，保护栅极并定义源漏扩展的注入边界。
- 主侧墙：SiN、SiOCN 或 SiO₂，厚度约 5–15 nm 量级，隔离栅极与源漏接触。
- 低-k 侧墙可降低栅极到源漏的寄生电容；空气侧墙是研究中的进一步方案。
- 自对准接触（Self-Aligned Contact, SAC）：利用氮化硅栅帽和侧墙，在接触孔刻蚀时保护栅极。

FinFET 的栅极从三面包围鳍，GAA 则从四面包围纳米片/纳米线。侧墙、内间隔（inner spacer）和沟道释放的工艺细节不同，但“用介质把栅极和源漏隔开”的目的相同。

### 6. 源漏工程

源漏不是简单的“高浓度注入区”，而是由多步注入和外延构成的低阻、低寄生结构：

- **源漏扩展（Extension）/轻掺杂漏（Lightly Doped Drain, LDD）**：低能量、较浅的注入，降低沟道边缘的电场峰值，抑制热载流子效应。
- **晕环（Halo）**：倾斜注入到源漏附近，提高局部掺杂、抑制短沟道效应。
- **深源漏（Deep Source/Drain）**：较高能量、高剂量注入，提供低阻通路。
- **抬升源漏（Raised Source/Drain）**：用选择性外延生长 SiGe:B（pMOS）或 Si:P/Si:C（nMOS）。SiGe 对 pMOS 提供压应变，Si:C/Si:P 对 nMOS 提供拉应变，从而提高载流子迁移率；原位掺杂还降低接触电阻。
- **激活退火（Activation Anneal）**：修复注入损伤、把掺杂原子放到替位位置。常用尖峰快速热退火（Rapid Thermal Anneal, RTA，约 1,000–1,100 °C，秒级）或激光退火（约 1,200–1,400 °C，微秒到毫秒级）。

退火的核心矛盾是“激活”与“扩散”：温度越高、时间越长，激活越充分，但结深和短沟道效应也越难控制。毫秒级退火让掺杂在来不及显著扩散时被激活，是超浅结的关键手段。

### 7. 硅化物与接触

源漏和栅极表面需要低阻接触。**硅化物（Silicide）** 通过金属与硅反应形成低阻金属硅化物：

- 早期用 TiSi₂、CoSi₂；先进节点主流是 NiSi，电阻率约 14–20 µΩ·cm（公开文献量级，2000s）。
- **自对准硅化物（Salicide）**：沉积 Ni（或 NiPt）后第一次退火形成富金属相，选择性去除未反应金属，再第二次退火形成低阻 NiSi。
- 硅化物不能太薄（电阻高），也不能太厚（消耗过多硅、增加结漏电）；高温下 NiSi 还会团聚，因此要控制后续热预算。
- 接触电阻率在先进节点目标约 10⁻⁹ Ω·cm² 量级（公开文献，2020s），接触面积缩小后，界面工程和肖特基势垒变得和掺杂一样重要。

接触孔通常用 Ti/TiN 作阻挡层和粘附层，再用化学气相沉积（CVD）钨（W）填充，最后 CMP。钨塞、硅化物和源漏共同构成器件的“外部电阻”，在先进节点中可能与沟道电阻相当甚至更大（公开文献量级，2020s），成为性能瓶颈。

### 8. 热预算

**热预算（Thermal Budget）** 是掺杂原子的扩散和材料反应在温度-时间上的累积。常用扩散长度估算：

```
L ≈ √(D·t)
```

其中 D 是掺杂在硅中的扩散系数，t 是时间。举例：若 D ≈ 10⁻¹³ cm²/s、t = 1 s，则 L ≈ 3 nm；若 t = 10 s，则 L ≈ 10 nm。这只是量级示例，真实 D 强烈依赖温度、掺杂浓度和缺陷。

FEOL 的温度层级大致是：

- 阱注入后的退火、栅氧生长：约 800–1,100 °C。
- 源漏激活：尖峰 RTA 1,000–1,100 °C 秒级，或激光退火 1,200–1,400 °C 微秒到毫秒级。
- 硅化物形成：约 250–500 °C。
- BEOL（铜/低-k）：通常控制在约 400–450 °C 以下，以免铜扩散、低-k 损伤和硅化物退化。

Gate-Last 的一个重要动机就是重新排列热预算：先做高温的源漏激活，再沉积对高温敏感的 High-k 和金属栅。这样每个材料只经历它能承受的温度。

## 深入理解

### 为什么 STI 的“角落”很难

STI 沟槽的顶部和底部拐角是电场集中点。刻蚀损伤、衬里氧化不足或填充空洞都会在这里引入漏电通道；CMP 的碟形凹陷会让后续栅极跨越台阶，造成栅氧厚度不均。工艺上常用圆角氧化、衬里层、致密化退火和 CMP 终点控制来缓解。STI 看起来只是“挖坑填氧化物”，实际上是在控制应力、电场和形貌三者之间的平衡。

### High-k 为什么必须搭配金属栅

High-k 解决了物理厚度与 EOT 的矛盾，但多晶硅栅会遇到两个问题：一是多晶硅耗尽（poly depletion）使有效栅氧变厚；二是费米能级钉扎（Fermi-level pinning）让 Vth 难以调节。金属栅提供更合适的功函数和更低的栅电阻，两者必须一起用。High-k 的界面层、结晶相、氧空位和偶极层都会影响 Vth，因此“换一种 High-k”远不是简单的材料替换。

### 应变工程：不是越大越好

SiGe 的晶格常数比 Si 大，外延在 pMOS 源漏中会对沟道施加压应变，提高空穴迁移率；Si:C 的晶格常数比 Si 小，对 nMOS 沟道施加拉应变，提高电子迁移率。但应变过大会产生位错、增加漏电和变异，且与后续热预算、硅化物和接触工艺耦合。应变工程是“材料、力学、器件”三者的联合优化。

### 源漏电阻与接触电阻

先进节点的沟道电阻下降，但源漏扩展、硅化物和接触电阻没有同比例下降。器件的总电阻可以粗略写成 R_total = R_channel + R_ext + R_contact。当 R_ext 和 R_contact 占比上升时，单纯提高迁移率或缩短栅长带来的收益会被抵消。这就是为什么先进节点大量投入在抬升源漏、原位掺杂、硅化物和 MOL 接触上。

### 变异从哪里来

FEOL 的变异源包括：随机掺杂波动（RDF）、栅边缘粗糙度（LER）、金属栅功函数晶粒（Metal Gate Granularity, MGG）、栅氧厚度波动、STI 应力和注入损伤。平面器件靠沟道掺杂控制 Vth，掺杂原子数越少，统计波动越大；FinFET 和 GAA 用更薄的沟道和更好的围栅控制来降低这种波动，但也带来新的几何变异和工艺复杂度。

### 热预算的“账本”思维

把每一步写成“温度 × 时间”的账本，比记住某个具体温度更有用。扩散长度按 √(D·t) 增长，意味着时间缩短 100 倍，扩散长度只缩短 10 倍；这也是毫秒/微秒退火能在保持浅结的同时激活掺杂的原因。Gate-Last、激光退火、低温硅化物和 BEOL 低温工艺，都是在同一本账上挪动支出。

## 总结

FEOL 用 STI 隔离器件、用阱和沟道注入设定电学背景、用 High-k/金属栅获得栅控、用侧墙和源漏工程降低寄生、用退火激活掺杂、用硅化物和接触降低外部电阻。每一步都受热预算约束，材料与顺序的选择往往比单个参数更重要。先进节点通过 FinFET/GAA、应变工程和界面工程继续缩放，但“在有限热预算内做出低变异、低寄生的器件”这一核心问题没有改变。
