# 工艺制造与先进封装 习题

> 八组计算覆盖晶圆几何、光刻、FEOL 热预算、BEOL RC、节点密度、芯粒拆分、先进封装与封装瓶颈。所有数字为课程量级或示例假设，不构成工艺设计套件（PDK）参数、采购报价或验收依据。

---

## 问题一：晶圆与 die 几何

**参数**：300 mm 晶圆，边缘排除 e = 3 mm；die 面积 A = 150 mm²；缺陷密度 D0 = 0.15 defects/cm²；晶圆价格按 $17,000/片（示例假设）。

**公式**：

```
每片毛 die 数 N ≈ π(D/2 − e)² / A − πD / √(2A)
Poisson 良率 Y = exp(−A·D0)
每颗合格 die 成本 ≈ 晶圆价格 / (N × Y)
```

**答案要点**：

1. 有效半径 147 mm，第一项 `π×147²/150 ≈ 452.6`；第二项 `π×300/√300 ≈ 54.4`；N ≈ 398 颗。
2. 晶圆面积 `π×150² ≈ 70,686 mm² = 706.9 cm²`；die 面积 1.5 cm²，面积比约 471，边缘与划片损失约 15%。
3. 良率 `Y = exp(−1.5×0.15) = exp(−0.225) ≈ 0.799`；合格 die ≈ 398×0.799 ≈ 318 颗。
4. 每颗成本 ≈ `17,000 / 318 ≈ $53.5`。若 D0 翻倍到 0.30，Y ≈ 0.638，合格 die ≈ 254 颗，成本升至约 $67；面积和 D0 比晶圆小幅涨价更敏感。

## 问题二：光刻分辨率与焦深

**参数**：193 nm 浸没式（NA = 1.35）、EUV 0.33 NA、High-NA EUV（NA = 0.55）；取 k₁ = 0.33、k₂ = 0.50 做量级估算。

**公式**：

```
R = k₁·λ / NA        （可分辨半周期）
Pitch = 2R
DOF = k₂·λ / NA²
```

**答案要点**：

1. **193 nm 浸没式**：λ = 193 nm，NA = 1.35。`R = 0.33×193/1.35 ≈ 48.2 nm`，pitch ≈ 96.4 nm；`DOF = 0.5×193/1.35² ≈ 53 nm`。
2. **EUV 0.33 NA**：λ = 13.5 nm。`R = 0.33×13.5/0.33 = 13.5 nm`，pitch = 27 nm；`DOF ≈ 62 nm`。
3. **High-NA EUV**：NA = 0.55。`R ≈ 8.1 nm`，pitch ≈ 16.2 nm；`DOF ≈ 22 nm`。焦深按 1/NA² 缩小，是 High-NA 工艺窗口变窄的根源。
4. **30 nm pitch 能否单次曝光**：需要 R = 15 nm。193i 的 `k₁ = R·NA/λ = 15×1.35/193 ≈ 0.105`，低于约 0.25 的理论下限，单次曝光不可行；需 SADP/SAQP 多重曝光，或改用 EUV（0.33 NA 在 k₁=0.33 时 R=13.5 nm，pitch=27 nm，原则上可覆盖）。
5. **工程含义**：High-NA 的 22 nm 焦深要求晶圆局部平坦度和扫描仪调平更严；这就是晶圆几何（见 [01](../notes/01-silicon-to-wafer.md)）会进入光刻预算的原因。

## 问题三：FEOL 顺序与热预算

**参数**：扩散系数 D = 1×10⁻¹² cm²/s（量级示例，实际强烈依赖温度与掺杂）；时间 t 取 1 s、1 ms，浅结目标 L ≤ 2 nm。

**公式**：扩散长度 `L ≈ √(D·t)`。

**答案要点**：

1. **主流程**：STI 隔离 → 阱/沟道注入 → 栅堆叠（Gate-Last 先做假栅）→ 栅极图形 → 侧墙 → 源漏扩展/晕环 → 抬升源漏外延 → 激活退火 → 硅化物 → 接触（MOL）。Gate-Last 在激活退火之后去除假栅，再沉积 High-k/金属栅。
2. **扩散长度**：t = 1 s 时 `L = √(1e-12) = 1e-6 cm = 10 nm`；t = 1 ms 时 `L = √(1e-15) ≈ 3.2×10⁻⁸ cm ≈ 0.32 nm`。毫秒/微秒退火能在激活掺杂的同时把扩散压到亚纳米级。
3. **浅结预算**：若要求 L ≤ 2 nm（2×10⁻⁷ cm），则 `t ≤ L²/D = 4×10⁻¹⁴ / 1×10⁻¹² = 0.04 s = 40 ms`。这解释了为什么尖峰 RTA 之后还要激光/闪光退火。
4. **为什么 Gate-Last**：High-k 和金属栅不经历 1,000–1,100 °C 的源漏激活，避免 High-k 结晶、界面层再生长和功函数漂移；代价是假栅去除、金属填充和 CMP 带来的额外步骤与套刻要求。
5. **热预算排序**：阱退火/栅氧约 800–1,100 °C；源漏激活约 1,000–1,100 °C 秒级或 1,200–1,400 °C 毫秒级；硅化物约 250–500 °C；BEOL 通常低于约 400–450 °C。顺序的本质是让每种材料只经历它能承受的温度。

## 问题四：BEOL RC 与中继器

**参数**：Cu 线 L = 1 mm，W = 30 nm，H = 60 nm，S = 30 nm；ρ = 1.68×10⁻⁸ Ω·m，εr = 2.5，ε0 = 8.854×10⁻¹² F/m；缓冲器延迟 30 ps。

**公式**：

```
R = ρ·L / (W·H)
C ≈ ε0·εr·L·H / S
RC ≈ R·C
```

**答案要点**：

1. `R = 1.68e-8×1e-3 / (30e-9×60e-9) ≈ 9,333 Ω ≈ 9.3 kΩ`（未计尺寸效应；实际有效电阻率更高）。
2. `C ≈ 8.854e-12×2.5×1e-3×60e-9/30e-9 ≈ 4.43×10⁻¹⁴ F ≈ 44.3 fF`。
3. `RC ≈ 9,333×4.43e-14 ≈ 4.13×10⁻¹⁰ s ≈ 0.41 ns`。
4. **缩放**：W、H、S 同时乘 0.7，R 变为 `1/0.7² ≈ 2.04×`，C 中 H/S 不变，RC 约 2.04×；再叠加表面/晶界散射，实际恶化更多。
5. **10 mm 长线**：RC 按 L² 增长，约 0.41 ns×100 ≈ 41 ns。分成 10 段、每段 1 mm：总 RC ≈ 4.1 ns，加 10 个缓冲器约 0.3 ns，总延迟约 4.4 ns，改善约 9.3×。
6. **最优点**：延迟近似 `RC_total/k + k·t_buf`，最优 `k = √(RC_total/t_buf) ≈ √(41/0.03) ≈ 37`，最小延迟约 `2√(RC_total·t_buf) ≈ 2.2 ns`；实际受面积、功耗和布线拥塞限制，不会取到理论最优。

## 问题五：节点命名、CPP/MP 与 SRAM 面积

**公式**：

```
单元高度 ≈ tracks × MP
单元面积 ≈ CPP × 单元高度
```

**参数**（示意，取自 [05](../notes/05-process-nodes.md)）：N7 CPP=57 nm、MP=40 nm；N5 CPP=48 nm、MP=30 nm；N3 CPP=45 nm、MP=24 nm（示意）；均按 6T 单元。

**答案要点**：

1. N7：高度 `6×40=240 nm`，面积 `57×240=13,680 nm²`。N5：`6×30=180 nm`，面积 `48×180=8,640 nm²`，相对 N7 缩小 `13,680/8,640 ≈ 1.58×`。
2. N3：`6×24=144 nm`，面积 `45×144=6,480 nm²`，相对 N7 约 `2.11×`。节点名从 7 到 3 缩小 2.33×，面积只缩小约 2.1×，CPP 只从 57 降到 45 nm。
3. **SRAM**：N7 ≈ 0.027 µm²，N5 ≈ 0.021 µm²，N3B ≈ 0.0199 µm²。N7→N3B 位单元面积只缩小到 0.737×（约 26%），远慢于逻辑的 0.474×。
4. **混合面积**：若 die 中 60% 是逻辑、40% 是 SRAM，N7→N3B 的总面积比为 `0.6×0.474 + 0.4×0.737 ≈ 0.58`，只缩小约 42%，而不是逻辑的 53%。
5. **判断正误**：（a）“N3 的栅长是 3 nm”——错，CPP 约 45 nm；（b）“Intel 10 与 TSMC N7 密度相近”——对，均在 90–100 MTr/mm² 量级；（c）“N4P 是全新 4nm 节点”——错，属于 N5 家族；（d）“NVIDIA 4N 是 4nm”——错，是 5nm 级定制平台；（e）“更先进节点每晶体管一定更便宜”——错，取决于晶圆价格、良率与设计复杂度。
6. **架构后果**：SRAM 缩放停滞使大缓存转向 3D 堆叠、缓存芯粒和 HBM，进而把压力转移到先进封装（见 [07](../notes/07-advanced-packaging.md)）。

## 问题六：Chiplet、UCIe 带宽密度与拆分

**参数**：UCIe 1.0 标准封装带宽密度 28–224 GB/s/mm，先进封装 165–1317 GB/s/mm；每 lane 32 GT/s；每比特能量 0.5 pJ/bit（标准）/0.25 pJ/bit（先进）。

**公式**：

```
单向带宽 = 速率(GT/s) × lane 数 / 8      （GB/s）
所需边缘 = 总带宽(GB/s) / 带宽密度(GB/s/mm)
D2D 功耗 = 比特率 × 每比特能量
```

**答案要点**：

1. **10 TB/s 的边缘预算**：标准封装 `10,000/224 ≈ 44.6 mm`；先进封装 `10,000/1317 ≈ 7.6 mm`。若芯片只有 2×20=40 mm 可用边缘，标准封装不够，必须用先进封装。
2. **UCIe x64 @32 GT/s**：`32×64/8 = 256 GB/s` 单向；x16 为 64 GB/s。注意 GT/s 是线路速率，不是有效载荷率，编码与协议开销会再打折。
3. **PHY 功耗**：256 GB/s = 2.048×10¹² bit/s；0.25 pJ/bit 对应约 0.51 W（单向），0.5 pJ/bit 约 1.02 W。10 TB/s 双向 D2D 在 0.25 pJ/bit 下约 20 W 量级，不可忽略。
4. **良率账**：总面积 800 mm²（8 cm²），D0=0.1。单片 `Y=exp(−0.8)≈0.449`；4×200 mm² 每片 `Y=exp(−0.2)≈0.819`，四片全好 `0.819⁴≈0.449`。泊松模型下整组良率不变。
5. **拆分的真实收益**：允许部分出货时，期望可用面积从 `0.449×800≈359 mm²` 提升到 `4×0.819×200≈655 mm²`；坏一颗只损失 200 mm²，且可先做 KGD 再封装。代价是 D2D 面积/功耗、封装和测试成本。
6. **什么时候不拆**：带宽需求低（标准封装够用）、跨 die 延迟敏感、die 本来就不大、或 D2D PHY 面积/功耗吃掉收益时，单片更划算。

## 问题七：先进封装剖面与 HBM 堆叠

**公式**：

```
HBM 带宽 = 位宽(bit) × 引脚速率(Gb/s) / 8      （GB/s）
HBM 容量 = 堆栈数 × 每堆栈容量
中介层面积 ≈ (逻辑 die 面积 + HBM 堆栈数 × 单堆栈占位) × (1 + 布线/禁布余量)
```

**参数**：HBM3E 1024-bit、9.6 Gb/s、24 GB/堆栈；HBM4 2048-bit、8 Gb/s、24–64 GB/堆栈；逻辑 die 800 mm²；HBM 堆栈占位约 11×11 mm；余量 20%；reticle 858 mm²；CoWoS-S 约 2,700 mm²。

**答案要点**：

1. HBM3E：`1024×9.6/8 ≈ 1,229 GB/s ≈ 1.23 TB/s/堆栈`。HBM4：`2048×8/8 = 2,048 GB/s ≈ 2.05 TB/s/堆栈`。
2. 8 堆 HBM3E 理论引脚带宽约 `8×1.23 ≈ 9.8 TB/s`。B200 标称 8 TB/s，约为引脚上限的 82%，差值来自控制器效率、功耗与热约束。
3. 容量：8×24=192 GB（B200 级）；8×36=288 GB（B300 级）。HBM4 16-Hi、32 Gb die 可达 `16×32/8=64 GB/堆栈`，8 堆即 512 GB 级别（路线图口径）。
4. **中介层面积**：`800 + 8×121 = 1,768 mm²`；乘 1.2 余量约 2,122 mm²，即 `2,122/858 ≈ 2.47× reticle`，落在 CoWoS-S 的约 2,700 mm² 内。
5. **12 堆**：`800 + 12×121 = 2,252 mm²`；乘 1.2 约 2,702 mm²，约 3.15× reticle，已顶到 CoWoS-S 上限，需要 CoWoS-L 或更大封装。
6. **凸点密度**：`1/pitch²`。40 µm → 约 625/mm²；25 µm → 1,600/mm²；10 µm → 10,000/mm²；40→10 µm 密度提升 16×。
7. **TSV**：1024/2048-bit 接口需要上千根数据 TSV，再加电源/地、测试和冗余；单堆栈 TSV 可达 2 万根以上（公开资料），这也是 HBM 堆叠良率与测试难度的来源。

## 问题八：封装瓶颈、供电、热与 KGD/测试成本

**参数**：功耗 700 W 或 1,000 W；Vdd = 0.8 V；环境/冷板入口 35 °C，Tj 上限 105 °C；PDN 电阻 0.1 mΩ；封装对角线 80 mm；CTE：Si 2.6 ppm/K、有机基板 16 ppm/K；ΔT = 100 K。

**公式**：

```
Tj = Ta + P × Rth
I = P / V
ΔV_IR = I × R_PDN
ΔL ≈ ΔCTE × ΔT × L
封装良率 ≈ 计算 die KGD × ∏(HBM KGD) × 组装良率
每颗良品成本 = 总投入 / 封装良率
```

**答案要点**：

1. **结温**：`Tj = 35 + 700×0.08 = 91 °C`，合格。若 Rth 恶化到 0.12 °C/W，`Tj = 35+84 = 119 °C`，超过 105 °C；该 Rth 下最大允许功耗 `(105−35)/0.12 ≈ 583 W`。
2. **电流与 IR drop**：`I = 1,000/0.8 = 1,250 A`。0.1 mΩ 产生 125 mV，占 0.8 V 的 15.6%，不可接受。要把 drop 控制在 5%（40 mV），需 `R < 0.04/1,250 = 0.032 mΩ`，只能靠大量并联凸点、厚 RDL 和片上去耦。
3. **翘曲一维估算**：`ΔL ≈ 13.4e-6×100×80 mm ≈ 0.107 mm = 107 µm`。若凸点高度仅约 40 µm，失配量已超过凸点间距量级；实际由底部填充、刚性框和对称叠层分担，但这说明大面积有机封装为何难做。
4. **整包良率**：`0.95×0.98⁸×0.98 ≈ 0.95×0.851×0.98 ≈ 0.79`。
5. **KGD 的价值**：若 HBM 不做 KGD、以 0.90 良率直接封装，整包良率 `0.95×0.90⁸×0.98 ≈ 0.40`。假设 die + 封装 + HBM 成本合计 $1,650，良品成本从 `1,650/0.79 ≈ $2,088` 升到 `1,650/0.40 ≈ $4,125`；即使 KGD 测试每堆 $8、8 堆共 $64，也远低于浪费的封装成本。
6. **测试边界**：终测只能筛掉坏品，不能追回已经花掉的中介层、HBM 和组装成本，所以 KGD 必须发生在封装之前；测试覆盖不足则把失效推给现场，代价更高。
