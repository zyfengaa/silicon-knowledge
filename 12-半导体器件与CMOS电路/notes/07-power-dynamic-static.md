# 07 — 动态功耗、静态功耗与能量

> **一句话结论**：互补金属氧化物半导体（CMOS）的总功耗由动态部分（开关、短路、毛刺）和静态部分（漏电）组成；动态项随 αCV²f 变化，静态项随温度和工艺指数上升，而真正约束设计的是每次操作的能量与散热能力，不只是瞬时功率。

---

## 为什么讲这个

前两篇解决了“门能不能工作”和“门有多快”，本篇回答“要花多少电”。功耗决定了芯片的供电、封装、散热和可靠性，也决定了架构能同时点亮多少晶体管。H100 SXM 的热设计功耗（Thermal Design Power, TDP）为 700 W，B200 为 1,000 W，B300/GB300 为 1,400 W（SPECS §1，模块级 TDP 口径），而电源电压仍大致在 0.6–1.2 V、阈值电压（Vth）在 0.2–0.6 V（SPECS §7）。在电压不能无限下降、频率又受延迟约束的前提下，能效成为比峰值算力更硬的指标。

本篇只到门/模块级的功耗来源、动态电压频率调节（DVFS）的 V-f 关系、能量指标和暗硅（Dark Silicon）概念。系统级的芯片热设计、封装热阻与暗硅的架构影响见 [功耗、能效与芯片热设计](../../11-系统分析与性能工程/notes/03-power-thermal.md)；门的结构与延迟模型见 [CMOS 反相器与静态 CMOS 逻辑](05-cmos-inverter.md) 和 [门延迟、RC 与逻辑努力](06-gate-delay-logic-effort.md)。机房液冷、电源使用效率（PUE）与冷量分配单元（CDU）属集群层，见兄弟仓库 [why-ai-cluster 散热篇](https://github.com/zyfengaa/why-ai-cluster/blob/main/02-芯片篇/07-功率越来越高散热怎么办.md)，本篇不展开。

## 核心概念

### 1. 动态功耗：开关、短路与毛刺

**动态功耗（Dynamic Power）** 是节点电压翻转时消耗的功率，主要由三部分组成：

```
P_dyn = P_sw + P_sc + P_glitch
P_sw = α · C · VDD² · f
```

其中 **开关功耗（Switching Power）** P_sw 是对电容充放电的功耗；**活动因子（Activity Factor, α）** 是每个时钟周期发生 0→1 翻转的概率；C 是总开关电容，包括栅电容、源漏扩散电容和互连电容；VDD 是电源电压；f 是时钟频率。

为什么是 CV²？考虑一个 0→1 翻转：电源通过 pMOS 向负载电容输送电荷 Q = C·VDD，电源做功 CVDD²；电容储能 ½CVDD²，另一半在充电通路的电阻/沟道中耗散。随后的 1→0 翻转把储能 ½CVDD² 在放电通路耗散。因此一个完整的 0→1→0 周期从电源取能 CVDD²。若 α 定义为每周期 0→1 的概率，平均功率就是 αCVDD²f。

α 的定义容易混淆：随机数据在 0/1 等概率且独立时，0→1 概率为 0.25；数据通路的活动因子常在 0.1–0.3，时钟网络约等于 1（每周期一次 0→1），这些都是公开估算（2000–2020 年教材/工业界经验值），依编码、负载和电路风格变化。若采用“跳变概率（0→1 或 1→0）”的定义，公式前要乘 ½。

**短路功耗（Short-Circuit Power）** P_sc 来自输入过渡期间上拉网络与下拉网络（PUN/PDN）同时导通。输入在 Vthn 与 VDD−|Vthp| 之间时，nMOS 和 pMOS 都未完全关断，VDD 到 GND 出现短暂直流通路。它随输入斜率变慢而增加，一阶近似为：

```
P_sc ∝ (VDD − 2Vth)³ · (t_slew / T)
```

精心设计、输入斜率与输出负载匹配时，短路功耗通常约占动态功耗的 5%–15%（公开教材估算，2000–2020 年）；输入过慢、VDD 较低或器件尺寸失衡时会显著上升。

**毛刺功耗（Glitch Power）** 来自组合逻辑中的冒险：不同路径延迟不等，使节点在稳定前发生多次虚假翻转。静态 CMOS 的毛刺不会破坏最终逻辑值，但会额外充放电。深逻辑树、路径严重失衡和宽扇入门更容易产生毛刺；平衡路径、流水化和消除静态冒险可以减少它。

### 2. 静态功耗：漏电的三种来源

**静态功耗（Static Power）** 是电路不翻转时仍然消耗的功率：

```
P_static = VDD · I_leak
I_leak ≈ I_sub + I_gate + I_junction
```

**亚阈值漏电（Subthreshold Leakage）** 是最主要的部分。MOSFET 关断时沟道并未完全消失，源漏之间仍有扩散电流：

```
I_sub = I0 · exp[(Vgs − Vth)/(n·kT/q)] · (1 − e^(−Vds/(kT/q)))
```

当 Vgs = 0 时，I_off 随 Vth 指数下降。衡量关断能力的指标是**亚阈值摆幅（Subthreshold Swing, S）**：

```
S = n·(kT/q)·ln10 ≈ 60–90 mV/dec
```

300 K 时理论下限约 60 mV/dec（kT/q·ln10 ≈ 59.6 mV/dec，SPECS §7），实际器件常在 70–90 mV/dec（2020 年代先进节点公开数据，量级）。S 越小，关断越彻底。短沟道效应、漏致势垒降低（DIBL）和阈值滚降（Vth roll-off）会降低有效 Vth，使 I_off 指数上升（见 [短沟道效应与 Dennard 缩放的终结](03-short-channel-dennard.md)）；这也是鳍式场效应晶体管（FinFET）/环绕栅极（GAA）用更强栅控来抑制漏电的原因（见 [FinFET、GAA 与后平面晶体管](04-finfet-gaa.md)）。

**栅极漏电（Gate Leakage）** 是栅氧的直接隧穿电流。栅介质越薄（等效氧化层厚度（Equivalent Oxide Thickness, EOT）越小），隧穿概率越高。**高 k 介质（High-k Dielectric）** 用 HfO₂ 等材料在保持栅控的同时增加物理厚度，从而降低隧穿；但它也带来界面态、迁移率退化和可靠性问题。**结漏电（Junction Leakage）** 包括源/漏与阱之间反偏结的漏电，以及高 Vds 下的**栅致漏极泄漏（Gate-Induced Drain Leakage, GIDL）** 和带间隧穿。

漏电还依赖电路状态：串联关断晶体管的“堆叠效应”会降低亚阈值漏电；输入向量不同，内部节点的电压不同，漏电也不同；多阈值电压（Multi-Vth）库用高 Vth 单元换低漏电，用低 Vth 单元换速度。

温度对漏电影响极大。温度升高时本征载流子浓度增加、Vth 下降，亚阈值漏电快速上升；经验上约每升高 10 °C 增大 1.5–2 倍（2000–2020 年公开工程经验值，工艺相关）。这形成正反馈：漏电升温 → 温度更高 → 漏电更大，严重时出现**热失控（Thermal Runaway）**。先进节点高结温下，静态功耗可占总功耗的 20%–40%（2010 年代先进节点公开估算，依工艺、电压、温度和负载）。

### 3. 电压、频率与 DVFS

频率与电压的关系不是线性的。短沟道器件的 alpha-power law 近似为：

```
f_max ∝ (VDD − Vth)^α / VDD,   α ≈ 1.3–2
```

在强速度饱和下，α 接近 1，常简化为 f ∝ (VDD − Vth)；在较低电压、接近阈值时，f 对 VDD 极其敏感，稍微降压就显著降频。**动态电压频率调节（Dynamic Voltage and Frequency Scaling, DVFS）** 就是利用这一点：负载轻时同时降低 VDD 和 f，负载重时再升回去。

由于 P_dyn ∝ VDD²·f，若 f 近似正比于 VDD，则 P_dyn ∝ VDD³。于是：

```
VDD 和 f 都降到 0.8 倍
P_dyn → 0.8² × 0.8 = 0.512 倍（约 −49%）
每次操作能量 E_op ∝ VDD² → 0.64 倍（−36%）
延迟 → 1/0.8 = 1.25 倍
EDP = E_op × 延迟 → 0.8 倍
```

但漏电不会按 VDD³ 下降，甚至可能因为延迟变长、漏电能量占比上升而抵消部分收益。因此总功耗的节省通常小于 49%。当 VDD 接近 Vth 时，频率崩塌、工艺偏差和噪声容限恶化，**近阈值计算（Near-Threshold Computing, NTC）** 的能效优势会被漏电和鲁棒性代价部分抵消。

### 4. 能量、能量-延迟积与能效指标

对固定任务，**每次操作能量（Energy per Operation, E_op）** 比瞬时功率更能反映能效：

```
E_op,dyn ≈ α·C·VDD²
```

**功率-延迟积（Power-Delay Product, PDP）** 在数值上等于每次操作能量；**能量-延迟积（Energy-Delay Product, EDP）** 和**能量-延迟平方积（Energy-Delay-Squared, ED²）** 则把速度纳入指标：

```
PDP = P × t_d = E_op
EDP = E_op × t_d
ED² = E_op × t_d²
```

在理想 f ∝ VDD 的缩放下，E_op ∝ VDD²、t_d ∝ 1/VDD，因此 EDP ∝ VDD，ED² 近似不变。这解释了为什么“降压降频”通常改善 EDP，却不一定改善 ED²；也解释了为什么架构评估常用 ED² 比较不同并行度/流水线方案。

数据搬运的能量往往远高于计算。Horowitz 在 ISSCC 2014 给出的 45nm、0.9 V 量级数据：

| 操作 | 能量（量级） | 相对 32-bit 整数加法 |
|---|---|---|
| 32-bit 整数加法 | ~0.1 pJ | 1× |
| 32-bit 浮点加法 | ~0.9 pJ | ~10× |
| 32-bit SRAM（静态随机存取存储器）读 | ~5 pJ | ~50× |
| 32-bit DRAM（动态随机存取存储器）读 | ~640 pJ | ~6000× |

这些数字随工艺、电压、带宽和实现方式变化很大，只用于说明“越远的数据搬运越贵”。它也是缓存层次、数据复用和近存计算（Processing-in-Memory）在能效上成立的根本原因。

### 5. 功耗墙、暗硅与缓解手段

**登纳德缩放（Dennard Scaling）** 曾保证：器件尺寸缩小、电压同步下降，单位面积功耗大致不变。这一规律在 2005 年前后失效（SPECS §7，详见 [短沟道效应与 Dennard 缩放的终结](03-short-channel-dennard.md)）：尺寸继续缩小，但 Vth 和 VDD 不能同步下降，漏电和短沟道效应又限制了电压下限。结果是在固定 TDP 下，芯片不能同时为所有晶体管供电到最高频率，出现**功耗墙（Power Wall）** 和**暗硅（Dark Silicon）**。

暗硅不是字面意义上的“坏掉”，而是“在给定散热预算下不能同时全速运行”。若每代晶体管密度翻倍、每晶体管功耗不变而 TDP 不变，则每代能全速使用的比例大约减半。Esmaeilzadeh et al. (2011) 的模型预测 8nm 级会有超过一半的晶体管无法同时全速供电；这是模型预测，不是产品实测，具体比例取决于功耗模型、散热和负载。

缓解手段可以分为“少翻转、少电压、少漏电、少同时工作”四类：

| 功耗项 | 物理来源 | 关键依赖 | 缓解手段 |
|---|---|---|---|
| 开关功耗 | 对栅/扩散/互连电容充放电 | α、C、VDD²、f | 时钟门控、DVFS、减小电容、数据编码 |
| 短路功耗 | 输入过渡时上拉/下拉网络（PUN/PDN）同时导通 | 输入斜率、VDD−2Vth、尺寸 | 合理尺寸设计、控制输入斜率、避免过慢输入 |
| 毛刺功耗 | 逻辑冒险造成虚假翻转 | 路径延迟失衡、逻辑深度 | 平衡路径、消除静态冒险、流水化 |
| 亚阈值漏电 | 关断沟道的扩散电流 | Vth、温度、VDD、器件几何 | 多 Vth、电源门控、体偏置、FinFET/GAA |
| 栅极漏电 | 栅氧直接隧穿 | EOT、VDD、栅面积 | High-k/金属栅、合理的 EOT |
| 结漏电/GIDL | 反偏结与高场隧穿 | 掺杂、VDD、温度、结面积 | 结工程、降低 VDD、版图优化 |
| 竞争电流 | 比例逻辑或浮空输入同时导通 | 电路拓扑、输入有效性 | 静态 CMOS、保持器/钳位 |

其中**时钟门控（Clock Gating）** 停止空闲模块的时钟翻转，直接降低 α；**电源门控（Power Gating）** 用多阈值 CMOS（MTCMOS）开关切断模块电源，直接消除漏电；**多阈值电压（Multi-Vth）** 在速度关键路径用低 Vth、非关键路径用高 Vth；**体偏置（Body Bias）** 通过调整 Vth 在速度和漏电之间折中。先进节点还用 FinFET/GAA 改善栅控、用 High-k/金属栅降低栅漏电。

## 深入理解

### 1. 活动因子与编码

α 不是常数，而是数据统计量。对总线，可以用“相邻两个周期不同比特的比例”来估算翻转率；对时钟，每个周期固定一次 0→1，α ≈ 1；对随机数据，若 0/1 独立等概率，0→1 概率为 0.25。编码可以降低 α：例如格雷码（Gray Code）让相邻状态只变一位，总线反转编码（Bus-Invert）根据汉明距离（Hamming Distance）决定是否整体取反，从而减少同时翻转的位数。代价是额外的编码/解码逻辑和延迟。

### 2. 短路功耗的权衡

短路功耗与输入斜率、输出负载和器件尺寸有关。输入边沿太慢，PUN/PDN 同时导通的时间变长；输出负载很大、输出翻转很慢时，输入已经完成过渡而输出仍在中间电平，短路电流也会持续更久。设计上要让输入斜率和输出斜率大致匹配，避免用极小尺寸的门驱动巨大负载，也避免为了省面积把整条路径的门都做成最小尺寸。短路功耗通常不是主要项，但在低 VDD、慢时钟、低活动度的待机电路中可能变得显著。

### 3. 漏电与温度的反馈

亚阈值漏电对温度呈指数依赖：

```
I_leak ∝ T² · exp(−q·Vth(T)/(n·k·T))
```

温度升高一方面增加本征载流子浓度，另一方面降低 Vth（典型温度系数约 −0.5 至 −2 mV/K，2000–2020 年公开教材估算），两者都使漏电上升。若散热不足，漏电产生的热量又进一步升温，可能形成热失控。因此高温、低电压、大面积的芯片要特别关注漏电预算；电源门控和动态热管理（降频/降压）是常见的阻断手段。

### 4. DVFS 的实际收益

DVFS 的收益取决于 f-V 曲线和漏电占比。若 f ∝ (VDD − Vth)，降低电压的边际频率损失在接近 Vth 时越来越大；若漏电占比高，降压带来的动态功耗节省会被“更长的运行时间 × 漏电”部分抵消。实际系统通常按预定义性能状态（P-state）工作，每个 P-state 对应一组（VDD, f）；切换需要锁相环（PLL）锁定和电压调节器响应时间，频繁切换本身也有开销。对延迟敏感或负载突发的场景，DVFS 的收益不如“关掉空闲模块”直接。

### 5. 暗硅的定量直觉

假设一代工艺晶体管密度翻倍，单管功耗不变，TDP 不变。若上一代能全速点亮 N 个晶体管，这一代只能点亮 N 个，占总数的 1/2；再下一代只能点亮 1/4。这个简单的“可用比例减半”模型解释了为什么多核时代没有出现“无限多核”：芯片面积可以继续增加，但同时全速运行的功耗预算没有同比增加。应对方式不是单纯增加通用核心，而是专用加速器（同样功耗下效率更高）、近阈值/低功耗域、电源门控和 3D 堆叠。系统级的暗硅讨论与数据见 [功耗、能效与芯片热设计](../../11-系统分析与性能工程/notes/03-power-thermal.md)。

### 6. 从门级功耗到架构决策

门级功耗模型给出三个可操作的杠杆：降低 VDD（二次方受益，但受频率和噪声容限约束）、降低 α（时钟门控、数据编码、减少无效翻转）、降低 C（更小的器件、更短的互连、更好的局部性）。架构层面则通过缓存层次、数据复用、低精度格式和专用数据通路减少“搬运 + 翻转”的总量。Horowitz 的能量表说明，一次 DRAM 访问的能量可以是几千次整数加法；因此“少搬数据”往往比“少做运算”更有效。这个结论与 [Roofline 模型](../../11-系统分析与性能工程/notes/01-roofline-model.md) 的性能视角互补：Roofline 看带宽瓶颈，能量表看每次搬运的代价。

## 总结

CMOS 功耗分动态和静态两大部分：开关功耗 αCV²f 是主体，短路和毛刺是补充；亚阈值、栅极和结漏电构成静态功耗，并在高温和先进节点下变得不可忽视。降压降频能显著降低动态功耗（理想情况下 P ∝ V³），但频率、噪声容限和漏电会限制收益；能量-延迟积和 ED² 用来衡量这种折中。Dennard 缩放失效后，固定 TDP 无法同时点亮所有晶体管，暗硅推动了专用加速器、电源门控和近阈值设计。把门级功耗模型与数据搬运能量结合起来，才能做出真正的能效决策。
