# 05 — CMOS 反相器与静态 CMOS 逻辑

> **一句话结论**：互补金属氧化物半导体（CMOS）反相器用互补的 p 沟道/n 沟道 MOSFET（pMOS/nMOS）开关把输出推到 VDD 或 GND；它的电压传输特性、噪声容限与“上拉/下拉网络对偶”是理解全部静态 CMOS 门、标准单元和后续延迟/功耗分析的起点。

---

## 为什么讲这个

模块 02 把金属氧化物半导体场效应晶体管（MOSFET）当作受栅压控制的开关，本篇回答“把开关连成逻辑门之后会发生什么”。反相器（Inverter）是最小、结构最完整的逻辑门：输入端看到栅电容，输出端在两条互补支路之间切换。弄清它的电压传输特性（VTC）、噪声容限和上拉/下拉网络（PUN/PDN）对偶，后面读标准单元库（Standard Cell Library）、综合网表、门延迟和功耗模型时就不会把“门”当成黑盒。本篇只到门级：器件 I-V 见 [MOSFET 如何工作](02-mosfet-operation.md)，短沟道效应（Short-Channel Effect）见 [短沟道效应与 Dennard 缩放的终结](03-short-channel-dennard.md)，功耗与热设计见 [功耗、能效与芯片热设计](../../11-系统分析与性能工程/notes/03-power-thermal.md)，标准单元版图与工艺节点见模块 13。

## 核心概念

### 1. 互补开关与两条网络

静态 CMOS（Static CMOS）反相器由一对互补器件组成：

- **上拉网络（Pull-Up Network, PUN）**：由 p 沟道 MOSFET（pMOS）构成。输入为低时 pMOS 导通，把输出拉向电源电压（VDD）。
- **下拉网络（Pull-Down Network, PDN）**：由 n 沟道 MOSFET（nMOS）构成。输入为高时 nMOS 导通，把输出拉向地（GND）。

对任意稳定的逻辑输入，PUN 与 PDN 恰好一个导通：

| 输入 Vin | nMOS | pMOS | 输出 Vout |
|---|---|---|---|
| 0 | 关断 | 导通 | VDD（逻辑 1） |
| 1 | 导通 | 关断 | 0（逻辑 0） |

这里的“互补”指控制逻辑互补，不是两个器件同时导通。稳态时没有 VDD 到 GND 的直流通路，这是静态 CMOS 低静态功耗的结构根源。输入从 0 跳到 1 的短暂过程中，两个器件会同时导通，形成**短路电流（Short-Circuit Current）**；它属于动态功耗的一部分，见 [动态功耗、静态功耗与能量](07-power-dynamic-static.md)。

### 2. 电压传输特性

**电压传输特性（Voltage Transfer Characteristic, VTC）** 是 Vout 随 Vin 变化的曲线。以 VDD = 1.2 V、nMOS 阈值电压（Threshold Voltage）Vthn 与 pMOS 的 |Vthp| 均为 0.3 V 为例，按 Vin 从 0 增大到 VDD，反相器经历五个区域：

| Vin 范围 | nMOS 状态 | pMOS 状态 | Vout 趋势 |
|---|---|---|---|
| 0 < Vin < Vthn | 关断 | 线性区 | 保持 VDD |
| Vthn < Vin < VM | 饱和区 | 线性区 | 从 VDD 下降 |
| Vin = VM | 饱和区 | 饱和区 | Vout = VM |
| VM < Vin < VDD − \|Vthp\| | 线性区 | 饱和区 | 接近 0 |
| VDD − \|Vthp\| < Vin < VDD | 线性区 | 关断 | 保持 0 |

其中 **VM** 是开关阈值（Switching Threshold），定义为 Vin = Vout 的点。高增益反相器的 VTC 在 VM 附近近似垂直：输入刚过 VM，输出迅速从高翻到低。这个陡峭程度由 VM 处的小信号增益（Small-Signal Gain）决定：

```
Av = dVout/dVin |Vin=VM ≈ −(gm_n + gm_p)(ro_n || ro_p)
```

增益越大，过渡区越窄，噪声容限越好；但增益会随 VDD 降低、器件短沟道化而变差。

### 3. 噪声容限

数字电路用电压区间表示逻辑值，区间之间必须留出抗干扰的余量。VTC 上定义四个关键电平：

- **VOH**：输出高电平的最小保证值；静态 CMOS 无负载时约为 VDD。
- **VOL**：输出低电平的最大保证值；无负载时约为 0。
- **VIH**：输入仍能被可靠识别为高电平的最低电压，通常取 VTC 斜率为 −1 的下交点。
- **VIL**：输入仍能被可靠识别为低电平的最高电压，通常取 VTC 斜率为 −1 的上交点。

噪声容限定义为：

```
NMH = VOH − VIH      （高电平噪声容限）
NML = VIL − VOL      （低电平噪声容限）
```

对高增益、对称的 CMOS 反相器，VM ≈ VDD/2，VIH 与 VIL 分布在 VM 两侧，NMH、NML 大约各为 0.3–0.45 VDD（公开教材估算，2000 年代典型值；依增益、工艺与负载而定）。VDD 越低，过渡区占比越大，噪声容限通常越差；这也是近阈值电路更难设计的原因之一。

### 4. β 比与开关阈值

**β 比（Beta Ratio）** 描述 nMOS 与 pMOS 的相对驱动能力：

```
βn = μn·Cox·(Wn/Ln)
βp = μp·Cox·(Wp/Lp)
βn/βp = (μn·Wn)/(μp·Wp)      （假设 Ln = Lp）
```

在长沟道、两管都处于饱和区的近似下，令 VM 处两管电流相等，可解出：

```
VM = [VDD + k·Vthn − |Vthp|] / (1 + k),   k = sqrt(βn/βp)
```

若 Vthn = |Vthp|，则 VM = VDD/2 要求 k = 1，即 βn = βp，也就是 Wp/Wn = μn/μp。硅中电子迁移率通常高于空穴迁移率，老节点上 μn/μp 约为 2–3（公开教材估算，2000 年代典型值；先进节点受应变与迁移率工程影响，需查 PDK），所以 pMOS 通常要比 nMOS 宽 2–3 倍才能得到对称的 VTC。

若 pMOS 不够宽，βn/βp > 1，nMOS 相对更强，VM 向低电压偏移；反之 VM 向高电压偏移。设计上可以通过调整 Wp/Wn 有意识地移动 VM，例如让某些门更容易拉低或拉高。

### 5. 静态 CMOS 门：NAND 与 NOR

把反相器的两条网络推广，就得到任意静态 CMOS 门：

- **PDN** 用 nMOS 实现“输出为 0”的条件；nMOS 串联表示“全部输入为 1”，并联表示“任一输入为 1”。
- **PUN** 用 pMOS 实现“输出为 1”的条件；其拓扑与 PDN 对偶：PDN 串联对应 PUN 并联，PDN 并联对应 PUN 串联。这是德摩根定律（De Morgan's Laws）在开关网络上的直接体现。

以二输入为例：

| 门 | PDN（nMOS） | PUN（pMOS） | 输出函数 |
|---|---|---|---|
| NAND2 | 两管串联 | 两管并联 | ¬(A·B) |
| NOR2 | 两管并联 | 两管串联 | ¬(A+B) |

静态 CMOS 门天然反相：它只能直接实现“非”函数。需要 AND/OR 时，通常在 NAND/NOR 后加一级反相器；这会增加延迟和面积，但换来全摆幅和低静态功耗。

**尺寸设计**的直观目标是最坏情况下与反相器有相近的驱动能力。NAND2 的最坏下拉路径是两只 nMOS 串联，等效沟道长度加倍，因此每只 nMOS 常取 2 倍宽度；NOR2 的最坏上拉路径是两只 pMOS 串联，因此每只 pMOS 常取 2 倍宽度。实际库还会考虑体效应、输入顺序和上升/下降延迟的折中：NAND 的下降沿较慢，NOR 的上升沿较慢，而 pMOS 本来就更弱，所以 NOR 的面积代价通常更大，CMOS 标准单元库中 NAND 的使用也更普遍。

### 6. 为什么静态 CMOS 几乎不耗静态功耗

稳态下，输入不是 0 就是 1，PUN 与 PDN 中总有一条网络完全关断。理想 MOSFET 的关断电阻无穷大，栅极又被氧化层隔离，因此：

因此没有 VDD→GND 的直流导通路径，栅极没有稳态直流输入电流，输出也不需要电阻分压——由导通的 pMOS 或 nMOS 直接接到电源轨。

所以在理想模型下，静态 CMOS 的静态功耗为零，输出也能达到轨到轨（Rail-to-Rail）。这也是静态 CMOS 取代 NMOS 逻辑、伪 NMOS 等比例逻辑（Ratioed Logic）的根本原因：后者在输出为低时仍有静态电流，噪声容限也更差。

但“几乎为零”只在理想模型下成立。真实器件存在**亚阈值漏电（Subthreshold Leakage）**、**栅极漏电（Gate Leakage）** 和**结漏电（Junction Leakage）**；先进节点、高结温下静态功耗可占相当比例。详见 [动态功耗、静态功耗与能量](07-power-dynamic-static.md)。此外，若输入悬空或处于中间电平，PUN/PDN 可能同时半开，产生额外电流，所以静态 CMOS 要求所有输入都被明确驱动。

### 7. 传输门

**传输门（Transmission Gate, TG）** 用一个 nMOS 和一个 pMOS 并联，栅极接互补控制信号，用来双向传递模拟或数字电平：

| 器件 | 传递 0 | 传递 1 | 原因 |
|---|---|---|---|
| 单个 nMOS | 好 | 差 | 高电平最多传到 VDD − Vthn |
| 单个 pMOS | 差 | 好 | 低电平最低只能到 \|Vthp\| |
| nMOS + pMOS 并联 | 好 | 好 | 两条路径互补，恢复全摆幅 |

传输门的优点是结构简单、适合做多路选择器（MUX）、锁存器和双向开关；缺点是输出节点可能浮空、存在**电荷共享（Charge Sharing）**、导通电阻随输入电平变化，而且它本身不恢复电平。把传输门输出接到下一级 CMOS 门之前，通常需要缓冲或保持电路，否则动态节点上的电荷会被后续级重新分配，造成误翻转。纯 nMOS 的传输晶体管逻辑（Pass-Transistor Logic）还有明显的阈值损失，必须谨慎使用。

## 深入理解

### 1. 开关阈值公式的适用边界

上面的 VM 公式假设器件工作在长沟道平方律饱和区、两管在 VM 处都饱和，并忽略短沟道效应、速度饱和、漏致势垒降低（DIBL）和体效应，以及阈值电压随位置的变化。

在先进节点，这些假设都不严格成立。速度饱和使电流更像线性而非平方关系，DIBL 让 Vth 随 Vds 变化，鳍式场效应晶体管（FinFET）/环绕栅极（GAA）的量化宽度也使“W/L”不再是连续可调的几何量。因此公式适合建立直觉和做一阶 sizing，最终数值必须用 SPICE 或标准单元库的时序/功耗模型确认。器件的短沟道行为见 [短沟道效应与 Dennard 缩放的终结](03-short-channel-dennard.md)。

### 2. 噪声容限不是“安全证书”

NMH/NML 是静态、单点的指标，只说明在输入被噪声缓慢推偏时，门还能不能保持正确输出。实际芯片还会遇到：

实际还会遇到动态噪声（电容耦合、串扰、电源噪声）、过慢的输入斜率（短路功耗与延迟增加）、工艺偏差（Vth/L/W 波动）以及慢 corner 下增益下降等问题。

所以噪声容限适合比较门的鲁棒性，不能替代静态时序分析（STA）、信号完整性分析和硅后验证。

### 3. 体效应与堆叠晶体管

在 NAND2 的串联 nMOS 中，上方器件的源极并不接地，而是接下方器件的漏极。源极电位升高会使上方 nMOS 的源-体反偏，**体效应（Body Effect）** 提高其阈值电压，进一步削弱串联堆叠的驱动能力。因此 NAND2 的下降延迟通常比“两个相同 nMOS 简单串联”的估算还差一些。NOR2 的串联 pMOS 也有类似问题，只是 pMOS 的体效应方向与 n 阱连接方式有关。

这也是为什么标准单元库不会简单地按“串联就加倍宽度”来设计，而是针对每个输入引脚、每个输出翻转方向做单独优化；同时，输入信号的到达顺序会影响内部节点电容的充放电，进而影响延迟。

### 4. 传输门的电荷共享

假设传输门输出节点原先被预充到 1 V，随后接通一个电压为 0.5 V、电容相当的节点。电荷在两个电容之间重新分配，公共节点电压会降到约 0.75 V，而不是保持 1 V。若这个节点直接驱动下一级反相器，可能造成误判或增加延迟。解决办法包括：

常见办法是加反相器/缓冲器重建电平、用保持器（Keeper）维持节点、控制开启时序避开预充/求值冲突，并避免让纯传输门直接驱动长线或大电容。

传输门的另一个代价是控制信号需要互补版本，布线复杂度和时钟/控制负载增加。因此在标准单元库中，传输门多用于触发器、锁存器和多路选择器，而不是替代所有组合逻辑。

### 5. 与比例逻辑的对比

伪 NMOS（Pseudo-NMOS）用一个始终弱导通的 pMOS 作上拉，用 nMOS 下拉网络实现逻辑。输出为低时 pMOS 与 nMOS 同时导通，存在静态电流；输出高电平也会因 IR 压降（IR Drop）低于 VDD。它面积小、输入电容低，适合某些高速/面积敏感场合，但静态功耗和噪声容限较差。静态 CMOS 用互补网络消除了这条直流路径，因此成为主流标准单元的基础。

## 总结

CMOS 反相器的核心是两条互补网络：PUN 在输入为 0 时把输出拉高，PDN 在输入为 1 时把输出拉低，稳态没有直流通路，因而输出轨到轨、静态功耗极低。VTC 的五个工作区决定了 VOH/VOL/VM/VIH/VIL，噪声容限由这些点定义；β 比决定 VM 的位置，对称设计通常需要 pMOS 比 nMOS 宽 2–3 倍。NAND/NOR 把反相器的结构推广为串联/并联对偶网络，但静态 CMOS 天然反相，且堆叠器件会受体效应和尺寸影响。传输门能双向传递全摆幅信号，却有浮空、电荷共享和非恢复性的问题。理解这些门级事实，是后续分析延迟、功耗和标准单元库的起点。
