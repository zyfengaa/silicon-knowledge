# 06 — 门延迟、RC 与逻辑努力

> **一句话结论**：门延迟可以拆成“本征延迟 + 驱动负载的延迟”，RC/Elmore 给出一阶时间常数，逻辑努力把两者归一化成可手算的 g/h/p 模型，用来在版图之前比较路径、级数和扇出。

---

## 为什么讲这个

上一篇回答“门是什么”，本篇回答“门有多快”。数字设计的性能通常以时钟周期衡量，而时钟周期又由组合逻辑路径、触发器开销和互连（Interconnect）延迟共同决定。RC（Resistance-Capacitance）模型让你看懂导线和晶体管网络为什么呈现“越长越慢、负载越大越慢”；逻辑努力（Logical Effort）则把不同门、不同扇出归一化到同一个延迟单位，使你能在架构评估阶段估算“这条路径大约几个 FO4（Fanout-of-4）”“加一级缓冲是否划算”。本篇的模型是**一阶估算**，用于设计空间探索和建立直觉，不替代静态时序分析（Static Timing Analysis, STA）或 SPICE 仿真。器件与工艺参数见 [MOSFET 如何工作](02-mosfet-operation.md)；门的 VTC 与噪声容限见 [CMOS 反相器与静态 CMOS 逻辑](05-cmos-inverter.md)；延迟与功耗的折中见 [动态功耗、静态功耗与能量](07-power-dynamic-static.md)。

---

## 核心概念

### 1. RC 阶跃响应与时间常数

最简单的延迟模型是一个电阻 R 驱动一个电容 C。输入阶跃后，输出按指数规律变化：

```
Vout(t) = VDD · (1 − e^(−t/RC))
```

关键时间点：时间常数（Time Constant）τ = RC 达到 63% 终值；50% 传播延迟（Propagation Delay）约 0.69·RC；10%–90% 上升时间约 2.2·RC，边沿斜率还会影响短路功耗与下一级延迟。

真实门不是线性电阻，器件电流随 Vgs、Vds 强烈变化；工程上常用**等效电阻（Equivalent Resistance）** 或电流源模型把非线性 I-V 线性化到某个工作点，再用 RC 公式估算。这个近似在电源电压较高、器件充分导通时较准，在近阈值和强短沟道条件下误差会变大。

### 2. Elmore 延迟

对由多个电阻、电容组成的 RC 树，逐个节点求解过于繁琐。**Elmore 延迟（Elmore Delay）** 用一阶矩近似整个网络的响应：

```
τ_Elmore = Σ_i C_i · (从输入到节点 i 的公共电阻)
三级梯形：τ = R1·C1 + (R1+R2)·C2 + (R1+R2+R3)·C3
```

它的物理含义是：每个电容 C_i 通过它与输入之间的总电阻充电，越靠后的电容看到的电阻越大，因此对延迟贡献越大。注意 Elmore 延迟是**时间常数/一阶矩**，不是直接的 50% 延迟：对单极点 RC，t_p50 ≈ 0.69·τ_Elmore；对分布 RC 线，τ_Elmore = RC/2，而 t_p50 ≈ 0.38·RC。对单调的 RC 树，Elmore 延迟通常是 50% 延迟的上界（Rubinstein et al., 1983），因此偏保守。

### 3. 门延迟的组成

把门看成“受控电流源 + 输出电容”，传播延迟可以写成：

```
t_p ≈ t_p0 + R_eq · C_L
```

其中 t_p0 是**本征延迟（Intrinsic Delay）**，来自器件自身的寄生电容和有限驱动能力；R_eq·C_L 是驱动外部负载的延迟。负载 C_L 包括下一级门的栅电容、本级的漏/源扩散电容和互连电容。

逻辑努力把这套关系无量纲化。定义：

**逻辑努力（Logical Effort, g）** 是在相同输出电流下门的输入电容与反相器输入电容之比；**电气努力（Electrical Effort, h）** 是 h = C_out/C_in，即广义扇出（Fanout）；**寄生延迟（Parasitic Delay, p）** 是门自身本征延迟，以反相器为 1 归一化。

于是单级延迟为：

```
d = g·h + p = f + p
```

f = g·h 称为**努力延迟（Effort Delay）**。延迟单位 τ 由工艺、电压、温度决定；在逻辑努力单位下，反相器的 g = 1、p = 1。

### 4. 路径延迟与最优级数

一条组合路径由 N 级门组成。把每级的量相乘/相加：

```
G = Π g_i                 路径逻辑努力
B = Π b_i                 路径分支努力
H = C_out / C_in          路径电气努力
F = G · B · H             路径总努力
P = Σ p_i                 路径总寄生延迟
D = Σ (g_i·h_i + p_i) = Σ f_i + P
```

其中**分支努力（Branching Effort）** b_i 描述本级的负载有多少在路径上、多少是“旁路”：

```
b_i = (C_onpath + C_offpath) / C_onpath
h_i = b_i · C_out_onpath / C_in
```

在给定 N 时，让每级努力相等（f_i = F^(1/N)）可使总努力延迟最小：D = N·F^(1/N) + P。最优级数由 F 和 f_opt 决定；对 p = 1 的反相器链，最小化 D 得到：

```
ln f_opt = 1 + p / f_opt
f_opt ≈ 3.59，工程上常取 4
N_opt ≈ ln F / ln f_opt
```

“每级努力约 4”是逻辑努力最常用的经验法则：路径总努力 F 越大，需要的级数越多；级数太少会导致每级扇出过大、延迟上升，级数太多则寄生延迟和触发器/缓冲开销占主导。

### 5. FO4 与扇出

**FO4（Fanout-of-4）** 指一个反相器驱动 4 个相同反相器输入时的延迟。按逻辑努力：

```
d_FO4 = g·h + p = 1×4 + 1 = 5τ
```

FO4 延迟是工艺的常用性能标尺：它同时包含本征延迟和中等负载驱动能力，比“晶体管截止频率”更接近真实逻辑路径。不同工艺的 FO4 延迟大致在：28nm 约 20 ps、16/14nm 约 10 ps、7nm 级约 5–8 ps（2015–2020 年公开估算，仅作量级；随 VDD、标准单元库（Standard Cell Library）和工艺-电压-温度（PVT）corner 变化很大）。

扇出与延迟的关系在逻辑努力模型中是线性的：d = h + 1（反相器）。真实曲线在高扇出、慢输入和速度饱和下会偏离直线，但“扇出越大、延迟越高”的趋势不变。设计上通常把单级扇出控制在 4 左右，避免出现一个门驱动几十个负载的“大扇出”节点。

### 6. 互连 RC 与中继器

片上导线不是理想连接。单位长度电阻 r 和电容 c 使长线呈现分布 RC 行为：

```
R = ρ·L/(W·H)            导线电阻，随宽度/厚度减小而增大
C ≈ c_per_length · L     导线电容，随长度线性增加
t_p50 ≈ 0.38·r·c·L²      分布 RC 线的 50% 延迟
```

没有中继器时，延迟随长度**平方**增长。**中继器（Repeater）** 是插入长线中的缓冲器，把一条长线切成多段，使总延迟从 ∝L² 变为近似 ∝L。按一阶模型，每段长度 l、共 k = L/l 段，总延迟为：

```
D ≈ k·[R_drv·C_drv + R_drv·c·l + r·l·C_drv + 0.38·r·c·l²]
```

对 k 求极值，得到最优段长 l_opt = sqrt(R_drv·C_drv/(0.38·r·c))，中继器数 k_opt = L/l_opt。

直观理解：段太短，中继器自身的本征延迟和面积/功耗占主导；段太长，导线 RC 又按平方增长。先进节点导线电阻上升、电容下降有限，RC 延迟在总延迟中的占比提高，因此中继器更密、布线层级更多，长距离通信也越来越倾向用串行器/解串器（SerDes）或 3D 互连而不是一根长线。

## 深入理解

### 1. 最优级努力的推导

把 N 级相同门、总努力 F 的路径延迟写成 D = N·f + N·p，其中 f = F^(1/N)。对 N 求导并令其为零：

```
dD/dN = f + p − f·ln f = 0
⇒ ln f = 1 + p/f
```

当 p = 1 时，解为 f ≈ 3.59；p 越大，最优 f 越大（级数相对更少），因为每增加一级都要付出寄生延迟。工程上取 f ≈ 4，既接近最优又便于心算。这个结论假设各级 p 相同、忽略分支和互连；真实路径应按级分别计算 g_i、p_i、b_i。

### 2. 一个手算例子

设路径为 NAND2 → 反相器，C_out/C_in = 20，无分支：

```
G = 4/3, F = G·H = 26.67
N = 2：f = sqrt(F) = 5.16，P = 3，D = 2×5.16 + 3 = 13.3τ
N = 3（中间加一级缓冲）：f = F^(1/3) = 2.99，P = 4，D = 3×2.99 + 4 = 12.97τ
```

三级略优于两级，但只快了约 2.5%，却多了一级面积、功耗和布线。这说明“最优级数”是连续模型下的数学最优点，工程上还要考虑缓冲器开销、时钟余量和功耗，不能只看 τ。

### 3. Elmore 的适用范围

Elmore 延迟对 RC 树是一阶近似，优点是只需拓扑和 R、C 值，不需要求解微分方程；缺点是只反映一阶矩，忽略高阶极点，对电感、传输线效应和强耦合不适用；对非单调波形、上冲/下冲和晶体管非线性，误差可能较大；对 RC 树通常偏保守，但在有电阻环路或强驱动时不一定；互连电容也不是集总参数，长线要用分布模型或多段梯形近似。

因此 Elmore 适合布线前的拓扑比较和粗略估算；签核阶段要用提取寄生参数后的 STA/SPICE。

### 4. 速度饱和与输入斜率

逻辑努力假设器件电流随尺寸线性缩放、输入是理想阶跃。短沟道器件进入**速度饱和（Velocity Saturation）** 后，电流更像受迁移率饱和限制，延迟不再严格按平方律缩放；此时常用 alpha 幂律（Alpha-Power Law）描述：

```
I_D ∝ (V_GS − V_th)^α,   α ≈ 1.3–2
```

这也是为什么先进节点的 FO4 延迟改善慢于“特征尺寸缩小”的直觉。另一方面，真实门的输入不是阶跃：**输入斜率（Input Slew）** 越慢，门在过渡区停留越久，延迟和短路功耗都增加；输入太快又会带来过冲、串扰和电迁移压力。标准单元库的时序模型会把输入转换时间作为参数，逻辑努力本身不包含这一维。

### 5. 中继器的工程折中

上面的中继器公式把中继器当成理想缓冲器，只计 R_drv、C_drv。真实设计中还要考虑中继器本身的面积、漏电和动态功耗，电源/地轨与布线资源，反相器中继器的极性翻转（需成对插入或调整逻辑），中继器尺寸（大于最小尺寸可降低长线延迟，但增加前级负载），以及先进节点导线电阻上升导致最优段长缩短、中继器数量增加。

一个常用的量级示例：取 r = 200 Ω/mm、c = 200 fF/mm、L = 5 mm，则 R = 1 kΩ、C = 1 pF、RC = 1 ns，分布 RC 的 50% 延迟约 0.38 ns。若每 0.5 mm 插入中继器，导线部分被切成 10 段，每段约 3.8 ps，合计约 38 ps；但还要加上每个中继器的本征延迟和驱动开销。这些数字只用于说明“分段把平方增长变成线性增长”，不是某工艺的签核值。

### 6. 逻辑努力不是签核工具

逻辑努力的价值在于快速回答“哪条路径更贵、级数是否合理、扇出是否失衡”。它不处理具体的上升/下降时间与输入斜率相关延迟、互连拓扑与串扰、工艺 corner 与电压/温度变化、器件老化，以及时钟树和触发器建立/保持时间。

因此设计流程通常是：用逻辑努力做早期架构和 RTL 阶段估算，用综合/布局布线后的 STA 做签核，用 SPICE 检查关键路径和定制单元。

---

## 总结

门延迟的一阶图像是 RC 充电：单极点 50% 延迟约 0.69RC，分布 RC 线约 0.38rcL²，Elmore 延迟用“每个电容看到的公共电阻”快速估算复杂 RC 树。逻辑努力把门归一化为 g、h、p 三个量，单级 d = gh + p，路径 D = N·F^(1/N) + P；最优每级努力约 4，FO4 反相器延迟为 5τ，是工艺性能的常用标尺。长线必须用中继器把平方延迟切成线性，代价是面积、功耗和布线复杂度。所有这些都是版图前估算，最终时序仍要用 STA/SPICE 在 PVT corner 下确认。
