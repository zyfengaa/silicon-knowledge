# 半导体器件与 CMOS 电路 习题

> 覆盖 PN 结、MOSFET 工作区、短沟道与缩放、FinFET/GAA、CMOS VTC、逻辑努力、功耗与 DVFS，以及 SRAM/Tensor Core 的跨层约束。参数为教学示例，计算时注明公式与单位。

---
## 一、PN 结与载流子
**题 1（掺杂、电导率与温度）** 硅 300 K，`n_i = 1.0×10^10 cm^-3`，`N_D = 1.0×10^16 cm^-3`，`μ_n = 1,400`、`μ_p = 450 cm²/(V·s)`。求 `n`、`p`、`σ`；若温度使 `n_i` 升到 `1.0×10^12 cm^-3`，重算 `p` 并说明对漏电的影响。  
**答案**：
```text
n ≈ N_D = 1.0×10^16 cm^-3
p = n_i²/N_D = 1.0×10^4 cm^-3
σ = q(nμ_n + pμ_p) = 1.6e-19×(1e16×1400 + 1e4×450) ≈ 2.24 S/cm
n_i = 1e12 时：p = 1e24/1e16 = 1.0×10^8 cm^-3
```
少子增加 4 个数量级，反偏结漏电和寄生双极效应增强，是高温静态功耗上升的器件根源。

**题 2（内建电势与耗尽区）** 对称突变结 `N_A = N_D = 1.0×10^16 cm^-3`，`n_i = 1.0×10^10 cm^-3`，`ε_s = 1.035×10^-12 F/cm`。求 `V_bi`、零偏 `W_0`、`V = −5 V` 时的 `W`，以及反偏 5 V 与零偏的结电容比。  
**答案**：
```text
V_bi = 0.0259×ln(N_A N_D/n_i²) = 0.0259×ln(1e32/1e20) ≈ 0.72 V
W = sqrt(4ε_s(V_bi−V)/(qN))，N = 1e16 cm^-3
W_0 = sqrt(4×1.035e-12×0.72/(1.6e-19×1e16)) ≈ 0.43 μm
W(−5)/W_0 = sqrt((0.72+5)/0.72) ≈ 2.82 ⇒ W ≈ 1.21 μm
C_j ∝ 1/W ⇒ C(−5)/C_0 ≈ 1/2.82 ≈ 0.35
```
反偏越深，耗尽区越宽、结电容越小；这是结电容随偏置变化的基础。

## 二、MOSFET 工作区与体效应
**题 1（工作区与电流）** nMOS：`μ_n C_ox = 300 μA/V²`，`W/L = 4`，`Vth = 0.4 V`，`λ = 0.1 V^-1`，`Vgs = 1.0 V`。求 `Vds = 0.3 V` 和 `1.0 V` 时的工作区与 `I_D`，并用 `r_o ≈ 1/(λI_D)` 求 `Vds = 1.0 V` 时的输出电阻。  
**答案**：
```text
Vov = 0.6 V。Vds=0.3 V < Vov，线性区：
I_D = 300×4×(0.6×0.3 − 0.3²/2) = 1,200×0.135 = 162 μA
Vds=1.0 V ≥ Vov，饱和区：
I_D = 0.5×300×4×0.36×1.1 ≈ 237.6 μA
r_o = 1/(0.1×237.6e-6) ≈ 42 kΩ
```
`λ` 反映沟道长度调制；短沟道器件 `λ` 更大、`r_o` 更低、本征增益更差。

**题 2（体效应与堆叠）** nMOS：`Vth0 = 0.4 V`，`γ = 0.4 V^(1/2)`，`2φ_F = 0.8 V`，`VSB = 0.6 V`，`Vgs = 1.0 V`。求体效应后的 `Vth`、饱和电流相对 `VSB=0` 的比例，并说明 NAND2 串联下拉的后果。  
**答案**：
```text
Vth = 0.4 + 0.4(sqrt(1.4) − sqrt(0.8)) ≈ 0.4 + 0.116 = 0.516 V
Vov: 0.6 → 0.484 V，I_sat 比 ≈ (0.484/0.6)² ≈ 0.65
```
上方串联 nMOS 的源极被抬高，体效应使其更弱；NAND2 下拉延迟比“两个相同 nMOS 简单串联”的估算更差，库需按输入位置和翻转方向单独 sizing。

## 三、短沟道效应、DIBL 与 Dennard 缩放
**题 1（DIBL 与关态漏电）** 某器件 `Vds = 0.05 V` 时 `Vth = 0.35 V`，DIBL = `80 mV/V`，`S = 80 mV/dec`，`Vdd = 1.0 V`。求 `Vds = 1.0 V` 时的 `Vth`、关态电流倍数；若 DIBL 恶化到 `150 mV/V`，重算倍数。  
**答案**：
```text
ΔVds = 0.95 V，ΔVth = −0.080×0.95 ≈ −0.076 V ⇒ Vth ≈ 0.274 V
Ioff 比 = 10^(0.076/0.080) ≈ 8.9×
DIBL=150 mV/V：ΔVth ≈ 0.1425 V，比 ≈ 10^(0.1425/0.08) ≈ 60×
```
DIBL 越大，漏压升高时关态漏电越失控，因此需要 FinFET/GAA 的强栅控。

**题 2（Dennard 缩放的算术）** 几何尺寸、电压、电流按 `κ = 0.7` 缩小，掺杂按 `1/κ` 增加。求面积、密度、电容、延迟、单次开关能量、单器件功耗和功耗密度的缩放倍数，并说明 2005 年后为何失效。  
**答案**：
```text
面积 κ²=0.49；密度 1/κ²=2.04；C ∝ κ=0.70；τ ∝ κ=0.70
能量 CV² ∝ κ³=0.343；单器件 P=CV²f ∝ κ²=0.49
功耗密度 = κ²/κ² = 1.00（不变）
```
电压不能继续按 `κ` 缩小：`S ≥ 60 mV/dec` 封死 `Vth` 下限，`Vdd` 停在约 1 V，漏电随短沟道和薄氧化层上升，功耗密度不再恒定。

**题 3（自然长度与栅控）** 取 `ε_s/ε_ox = 3`、`t_ox = 1 nm`，要求 `L > 3λ`。分别对 `t_body = 10 nm` 和 `5 nm` 求 `λ` 和最小 `L`，并说明 FinFET/GAA 为什么把体做薄。  
**答案**：
```text
λ ≈ sqrt((ε_s/ε_ox)·t_ox·t_body)
t_body=10 nm：λ=sqrt(30)≈5.48 nm，L>16.4 nm
t_body=5 nm： λ=sqrt(15)≈3.87 nm，L>11.6 nm
```
薄体降低 `λ`，让栅极在更短沟道下仍能控制势垒；FinFET 的薄鳍和 GAA 的薄片都是在降低 `t_body`、增加栅极耦合面积。

## 四、FinFET/GAA 与有效宽度
**题 1（FinFET 宽度量子化）** 取 `H_fin = 40 nm`、`W_fin = 8 nm`。求单鳍和 3 鳍的 `W_eff`；若需要 `300 nm`，最少几条鳍？量化浪费多少？  
**答案**：
```text
W_eff,1 = 2×40 + 8 = 88 nm；3 鳍 = 264 nm
300 nm 需 4 鳍 = 352 nm
浪费 = (352−300)/300 ≈ 17.3%
```
多出的宽度带来额外栅电容、动态功耗和面积；低驱动单元尤其不划算。

**题 2（GAA 纳米片）** 取 `W_sheet = 30 nm`、`T_sheet = 6 nm`、`N_sheet = 3`。求 `W_eff`；若用 3 层片得到约 `264 nm`，片宽应取多少？比较 FinFET/GAA 的宽度粒度。  
**答案**：
```text
W_eff = 3×2×(30+6) = 216 nm
目标 264：3×2×(W_sheet+6)=264 ⇒ W_sheet=38 nm
```
FinFET 只能按整数条鳍跳变（88 nm 一档），GAA 片宽可在设计规则内连续调节；GAA 粒度更细、量化浪费更小，但受光刻、刻蚀和寄生电容约束。

## 五、CMOS VTC 与噪声容限
**题 1（开关阈值与 β 比）** `VDD = 1.2 V`，`Vthn = 0.3 V`，`|Vthp| = 0.3 V`，`βn/βp = 4`。求 `VM`；要使 `VM = 0.6 V`，β 比应为多少？若 `μn/μp = 2.5`、`L` 相同，求 `Wp/Wn`。  
**答案**：
```text
k = sqrt(4) = 2
VM = (1.2 + 2×0.3 − 0.3)/(1+2) = 1.5/3 = 0.5 V
VM=0.6：(1.2+0.3k−0.3)/(1+k)=0.6 ⇒ k=1 ⇒ βn/βp=1
β = μC_ox(W/L) ⇒ Wp/Wn = μn/μp = 2.5
```
`VM=0.5 V` 说明 nMOS 相对更强；对称 VTC 需要更宽的 pMOS，因为空穴迁移率较低。

**题 2（噪声容限）** `VOH = 1.2 V`、`VOL = 0 V`、`VIH = 0.65 V`、`VIL = 0.45 V`。求 `NMH`、`NML`；高/低电平各加 `0.5 V` 噪声时哪侧先失效？若 `VDD` 降到 `0.6 V`，噪声预算如何变化？  
**答案**：
```text
NMH = 1.2 − 0.65 = 0.55 V；NML = 0.45 − 0 = 0.45 V
低电平 0.5 V > NML，先失效；高电平还剩 0.05 V 余量
VDD=0.6 V 按比例：VIL≈0.225、VIH≈0.325
⇒ NMH≈0.275 V、NML≈0.225 V
```
绝对噪声预算几乎减半，而耦合/电源噪声未必同比减小，所以低压/近阈值设计更难，SRAM 的 `Vmin` 更高。

## 六、逻辑努力与路径延迟
**题 1（三级路径）** 路径 `INV → NAND2 → INV`，`H = 20`，无分支。反相器 `g=1,p=1`，NAND2 `g=4/3,p=2`。求 `G`、`F`、三级最优延迟 `D`，并与两级 `NAND2 → INV` 比较。  
**答案**：
```text
G = 1×4/3×1 = 4/3；F = G·H = 26.67
N=3：f=26.67^(1/3)≈2.99，P=1+2+1=4
     D=3×2.99+4≈12.97τ
N=2：f=sqrt(26.67)≈5.16，P=2+1=3
     D=2×5.16+3≈13.3τ
```
三级快约 2.5%，但多一级面积、功耗和布线；逻辑努力的最优点还要和工程开销权衡。

**题 2（FO4 与频率）** 某工艺 `FO4 = 6 ps`，上题三级路径 `12.97τ`。求 FO4 的归一化延迟、路径绝对延迟、忽略时钟开销的最高频率，以及留 25% 余量后的频率。  
**答案**：
```text
FO4：d = 1×4 + 1 = 5τ
路径 = 12.97×6 ps ≈ 77.8 ps
f_ideal = 1/77.8 ps ≈ 12.9 GHz
25% 余量：T = 77.8/0.75 ≈ 103.7 ps ⇒ f ≈ 9.6 GHz
```
真实芯片还要加触发器 `t_clk-q`、建立时间、时钟偏斜/抖动、互连 RC 和 PVT corner，实际频率会明显更低。

## 七、动态/静态功耗与 DVFS
**题 1（开关功耗与降压降频）** `α = 0.2`，`C = 100 pF`，`VDD = 1.0 V`，`f = 2 GHz`。求 `P_dyn`；若 `VDD` 和 `f` 都降到 0.8 倍，求新功耗、比例和 `E_op = αCVDD²` 的比例。  
**答案**：
```text
P_dyn = 0.2×100e-12×1.0²×2e9 = 0.04 W = 40 mW
0.8×：P = 0.2×100e-12×0.64×1.6e9 ≈ 20.5 mW
比例 = 0.8²×0.8 = 0.512（约 −49%）
E_op：20 pJ → 12.8 pJ（−36%）
```
延迟变为 `1/0.8=1.25×`，EDP `=0.64×1.25=0.8×`；降压降频改善能量/EDP，但以性能为代价，收益还会被漏电侵蚀。

**题 2（漏电与温度）** `10^9` 个晶体管，平均关态漏电 `1 nA`，`VDD=1.0 V`。求静态功耗；温度升高 20 °C、每 10 °C 漏电乘 1.7 时的新功耗；电源门控关掉 90% 模块后的剩余功耗。  
**答案**：
```text
I_leak = 1e9×1e-9 = 1 A ⇒ P_static = 1.0×1 = 1 W
+20 °C：1.7²=2.89 ⇒ P ≈ 2.89 W
门控 90%：P ≈ 0.1×2.89 ≈ 0.29 W
```
漏电对温度指数敏感，形成“漏电升温 → 温度更高 → 漏电更大”的正反馈；电源门控直接切断关断模块供电。

## 八、跨层综合：SRAM 与 Tensor Core 的器件约束
**题 1（SRAM 面积与缩放）** N5 级 6T bitcell 约 `0.021 μm²`（公开估算），缓存 `64 MiB`。求总 bit 数、bitcell 阵列面积、含 30% 外围开销的总面积；若下一代 bitcell 只缩小 5%、逻辑缩小 30%，说明缓存占 die 比例的变化。  
**答案**：
```text
bits = 64×2^20×8 ≈ 5.37×10^8
array = 5.37e8×0.021 μm² = 1.13e7 μm² = 11.3 mm²
total = 11.3×1.3 ≈ 14.7 mm²
下一代 bitcell 0.0200 μm² ⇒ 阵列约 10.7 mm²（−5%）
```
同样功能的逻辑缩小 30%，缓存占比上升；SRAM 密度成为大芯片的面积瓶颈，架构上需要更多层次、压缩、scratchpad 和 HBM。

**题 2（MXU 尺寸与利用率）** TPU v1 的 MXU 为 `256×256`，`65,536` 个 8-bit MAC，峰值 `92 TOPS INT8`，TDP `75 W`。求 MXU 时钟（每 MAC 每周期 2 次操作）；求 `128×128×128` 矩阵乘的周期与利用率；求 `1024³` 的总 MAC 数和理想周期。  
**答案**：
```text
f = 92e12/(65,536×2) ≈ 0.70 GHz
128² 输出占阵列 1/4，K=128 ⇒ 128 周期，利用率 (128/256)²=25%
1024³：MAC = 1.074×10^9；周期 = 1.074e9/65,536 = 16,384
```
tile 越大，大矩阵复用越高，但小矩阵的利用率损失也越大。

**题 3（精度与 Tensor Core 面积）** B200 dense 峰值：FP16 `2,250 TFLOPS`，FP4 `9,000 TFLOPS`（SPECS §1）。假设 FP4 乘法器面积约为 FP16 的 1/4。解释 4 倍吞吐与面积/位宽的关系；为什么不能所有训练/推理都用 FP4；这对 tile 和 SRAM 带宽提出什么要求？  
**答案**：
```text
4× 吞吐 ≈ 同面积塞下 4× 低精度 MAC（或多核 4× 更小乘法器）
按题设 FP4 乘法器面积约为 FP16 的 1/4；纯平方律下 16→4 bit 理论更小，实际受累加/布线/控制限制
```
FP4 动态范围/精度有限，训练中的梯度、激活和累加通常需要 FP16/BF16/FP32 混合精度，量化/缩放和软件生态也要配套。低精度让单位面积/带宽服务更多 MAC，但需要更大的 tile 复用和更高 SRAM 带宽喂饱阵列，否则会被数据搬运卡住。
